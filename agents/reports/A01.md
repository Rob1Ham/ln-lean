(and adds its report). Comparing `d5b8e94^..d5b8e94`:

- **Theorem statement unchanged.** The statement of
  `backwardConserves_sender_eq_last_add_feeSum` is token-for-token the same:
  `p.2.val = lastAmount (p :: rest) + (rest.map hopFee).sum`.

  added, no conclusion was weakened, and no downstream theorem statement was edited.

  `forwardAmounts path = path.map (fun p => p.2.val)`. This is extensionally identical
  to the old recursive definition on every list: `[] ↦ 0`, `[p] ↦ p.2.val`, and
  `p :: q :: rest ↦ lastAmount (q :: rest)`. The module records the three equation
  lemmas as `rfl` simp lemmas.
- No `True`, `sorry`, `axiom`, `admit`, `native_decide`, or extra assumption was added
  to the file. The new proof uses ordinary induction plus `ac_rfl`.
- The changed proof is a performance refactor, not a semantic weakening.
