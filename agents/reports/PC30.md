## Remaining gaps / discoveries

1. **Unconditional negotiation commutativity is false.**  The required bit is
   an asymmetric disjunct in BOLT 1's `negotiated` rule.  This module records a
   concrete counterexample (`negotiated_not_commutative_unconditional`) and
   proves the exact pointwise condition (`negotiated_comm_iff`) plus the
   standard global sufficient condition (`negotiated_comm_of_mutually_accepted`).
2. **Bitwise `intersection` is not support-set intersection.**  If one peer
   requires feature `n` (even bit) and the other only offers it (odd bit), both
   support `n`, but the bitwise AND contains neither bit.  FeaturesProps already
   records this as `bitwiseIntersection_not_negotiation`; this module proves
   only the valid inclusion `supportSet_intersection_subset`.  A future module
   that wants a true support-set intersection should use `mutualSupport` or
   normalise required/optional bits first.
3. No further bridge is blocked.  The next smallest extension would be a
   byte-level `FeatureCodec` round-trip used to transport these pointwise laws
   to serialized `init` vectors, but that is outside PC30's scope.
