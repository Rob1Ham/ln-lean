### Important correction (do not overclaim)

The mission's literal claim "`channel_ready` is unreachable before
`funding_signed`" is **false in the current wave-A model**. `Step` has no
field remembering that `funding_signed` occurred. Both `fundingSigned` and
`fundingLocked` are enabled in `awaitingLockin`; in particular
`fundingCreated` immediately enables `fundingLocked`. The checked theorem
`channelReady_reachable_without_fundingSigned` gives the explicit
counterexample trace `[fundingCreated, fundingLocked]`. The corrected claim
proved here is: `fundingLocked` requires `awaitingLockin`, and the positive
trace statement is left as `LN-CH-010`. Making the BOLT 2 ordering an
invariant requires adding a `fundingSignedSeen`/message-history field to
`Channel` (or a trace-history field), which is outside B10's writable files.

A second, smaller model note: BOLT 2 permits `shutdown` before
`channel_ready` (`02-peer-protocol.md:2150-2152`), while the wave-A `Step`
relation enables `shutdown` only in `normal`. The phase-order theorems are
therefore about the model as written, not a claim of full BOLT 2 coverage.

## 4. What remains open and the next smallest proof step

1. **`LN-CH-010`** — prove `trace_to_normal_contains_fundingLocked`.
   Next step: induct on `Trace`; in the `cons` case split on whether the
   intermediate channel is already `normal`. If it is, apply the induction
   hypothesis to the prefix. If it is not, use
   `step_phaseRank_monotone` plus `step_allowedPhaseTransition` to show the
   last step must be `fundingLocked` (only constructor whose target is
   `normal`).
2. **BOLT ordering gap** — add a history flag/field (owned by the wave-A
   channel model, not B10) so that "`channel_ready` only after
   `funding_signed`" becomes expressible. Then prove the conditional trace
   invariant.
3. **Retransmission / `AwaitingRemoteRevoke` queue** — the model records one
   legal event but not the deferred `commitment_signed` queue; proving
   counter behaviour under queued updates needs a new list-of-pending-updates
   model.
4. **`shutdown` before `channel_ready`** — add the BOLT-permitted
   `awaitingLockin → shuttingDown` edge if the wave-A model is extended;
   the current phase-order theorem is deliberately limited to the existing
   relation.
