## 3. Proof approach

The parser is total but fuel-bounded, so the proof has two layers.

1. **Record layer.**  `parseRecord_encode_append` shows that parsing
   `BigSize(type) || BigSize(len) || value || rest` returns the original record
   and `rest`.  The two `BigSize` fields are decoded with
   `decode_encode_append`, which extends the existing `decode_encode`
   round-trip law to a value followed by an arbitrary suffix (the decoder only
   reads a bounded prefix).  `List.drop_left` and `List.take_left` then show
   that the remaining bytes are exactly `rest`; `value_toByteArray` converts
   the taken byte list back to the original `ByteArray` using
   `Array.toArray_toList`.
2. **Stream layer.**  `bytesToList_encodeTLV` identifies the stream encoding
   with the `flatMap` of record encodings.  `decodeTLVGo_encode` inducts on the
   record list and generalises the fuel: each `parseRecord` step consumes one
   fuel unit, and `rs.length ≤ fuel` is preserved for the tail.  Since a record
   encoding is nonempty (`one_le_encodedSize`), the `nil` branch is the only
   one that can terminate.  Finally the top-level fuel `(encodeTLV s).size + 1`
   is sufficient because `s.records.length ≤ sum encodedSize =
   (encodeTLV s).size` (`length_le_sum_encodedSize` and `encodeTLV_size_eq`).

Canonicality enters only through `h.2.2 : ∀ r ∈ s.records, r.InDomain`; the
ordering/uniqueness components are not needed by the decoder, consistent with
`decodeTLV_accepts_duplicate_types`.
