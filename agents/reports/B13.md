## 4. What remains open, and the next smallest step

Model gaps (recorded rather than silently weakened):
1. `addHTLC` has no `htlc_minimum_msat` parameter. `add_amount_within_bounds`
   therefore takes `minMsat.val ≤ amount.val` as a hypothesis, and
   `addHTLC_ignores_htlc_minimum` proves the model accepts an amount below a
   nominal minimum. Next step: add the minimum to `LnLean.Channel.HTLC.addHTLC`
   in wave B/C (owned by A4's successor, not this file) and restate
   unconditionally.
2. `addHTLC` has no current-height parameter, so "expiry strictly greater than
   the current height" is not available at add time. The proved statement is
   the timeout-side contrapositive (`timeout_before_expiry`/
   `offered_future_expiry_not_timed_out`); the add-side condition is an
   explicit hypothesis at the call site.
3. Preimage uniqueness is conditional on byte-array injectivity of `hashFn`
   (the shape of assumption C1). No SHA-256 implementation is imported and no
   axiom is introduced.
4. Value conservation across the commitment (balances + HTLC outputs + fee)
   is out of scope for this module; it needs `Channel/Commitment`.

Open obligations:
* `LN-HTLC-010`: prove `htlcSet (removeFromSet id hs) =

  `List.filter_cons` and Boolean commutativity of the two predicates.
* `LN-HTLC-011`: prove `totalHtlcValue hs ≤ hs.length * m` by induction on
  `hs`, using `Nat.succ_mul` and `omega`.
