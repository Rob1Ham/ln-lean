## 4. What remains open, and next smallest step

1. **No parser exists in the shipped model.**  `LnLean.Payment.Invoice` has
   no `parse`/`decode` function, so "network and payee are preserved by
   parsing" cannot be stated about the production model.  B25 states it for
   `decodeSemantic`, a semantic-field decoder defined in the proof file that
   performs the BOLT 11 reader checks and applies defaults.  The bech32
   layer, checksum, HRP string handling, and signable-digest construction are
   not modelled and no encoding theorem is claimed
   (`LN-PAY-INVOICE-ENCODING`).
2. **Amount positivity is not in `Invoice.Valid`.**  `exists_valid_zero_amount`
   proves the current predicate admits `some 0`; `amountSatisfies_none` also
   admits a zero payment when no amount is specified.  The next smallest model
   change is to add `amountPositive : ∀ a, i.amount = some a → 0 < a.val` to
   `Invoice.Valid` (owner: A7's file), after which
   `valid_amount_bound_and_positive` applies with `hp := h.amountPositive`.
3. **Signature soundness.**  `verify_authorized_under_assumption` is only as
   strong as its `sound` field.  The next step is to instantiate
   `InvoiceSignatureAssumption.accepts` with `LnLean.Crypto.Model.ecdsaVerify`
   and derive `sound` from the named C3 property in the crypto layer (a
   B06/B25 boundary, deliberately out of this file's import set).
4. **Expiry domain.**  `Timestamp = Nat`; LDK's `checked_add` overflow branch
   in `would_expire` has no counterpart.  The monotonicity theorems are
   therefore in the unbounded `Nat` domain.  Next step if bounded semantics
   are wanted: model `Timestamp` as a 35-bit subtype and reprove
   `validAt_iff` with an overflow hypothesis.
5. **Decoded-expiry monotonicity.**  The next smallest proof inside this file
   is: if `r.expiry = some e` and `decodeSemantic r = some i`, then
   `e ≤ e' → i.validAt t → validAt t` for an invoice decoded with `e'`
   (requires a second decoder or an explicit `expiry`-update lemma).  It is a
   three-line `simp`/`omega` proof once the raw-decoder variant exists.
