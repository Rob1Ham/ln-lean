- Statement fidelity: `bindChannel`, `ChannelAnnellation`, `ChannelBinding`,
  and every model/`GossipProps` definition are used unchanged.  The original
  catalog statement is not restated as if true.  Instead:
  * `waveE_e39_unconditional_capacity_positive_false` mechanises its negation;
  * `waveE_e39_bindChannel_capacity_pos_iff` gives the strongest true

  * `bindChannelPositive` is a *new* admission wrapper, not a silent edit of
    the model's `bindChannel`, so existing statements and proofs about
    `bindChannel` remain valid.

  BOLT 7 defines `capacity` as the funding output value, which is positive on
  L1; wave A stores `capacitySat : Nat` with no such invariant, hence the gap.

## Remaining gap / next step

The model gap is exactly the missing field invariant/admission check
`0 < ChannelAnnellation.capacitySat` before a binding is accepted.  Two model
fixes would close `LN-GOSSIP-002` at the source:

1. add the positivity check to `bindChannel` (or to the store's
   announcement-admission path), or
2. change the field to a subtype `{n : Nat // 0 < n}`.

Either change belongs to the model owner (`LnLean/Proofs/Routing/GossipProps.lean`
or `LnLean/Routing/Gossip.lean`), not this lane.  The existing `sorry` for
`bindChannel_capacity_positive` in `GossipProps.lean` is untouched.  The
eventual L1 link (capacity equals the funding output value of the announced
outpoint) remains outside the wave-A model.
