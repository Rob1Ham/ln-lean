## 4. What remains open and the next smallest step

Open:

* 35 `statementOnly` obligations (the catalog is the plan, not the proof).
* The L1 script bridge for funding/`to_local`/HTLC-timeout/penalty output
  semantics (see `docs/ROADMAP.md` §2).
* Explicit use-site hypotheses for C1--C8; `CryptoAssumptions` currently
  records the shapes but the cryptographic interface lives in wave-B
  `LnLean.Crypto.Model`.
* The global conservation theorem over all channels (`LN-SEC-002`) and
  liveness after `channel_reestablish` retransmission (`LN-PR-005`,
  `LN-SEC-003`).
* The two docs are maintained by hand; there is no generator wired into the
  build in this wave. They were checked against the Lean catalog: all 48 ids
  appear exactly once in each of `Obligations.lean`, `THEOREM-INDEX.md`, and
  `TRACEABILITY.md`, with no extras.

Next smallest step: add a `CommitmentView` (to-local, to-remote, in-flight
HTLC list, fee) and prove `sum(outputs) + fee = funding` by list induction,
then lift that to `LN-SEC-002`. This is the first item in the roadmap order
**conservation -> HTLC -> revocation -> routing -> liveness**.
