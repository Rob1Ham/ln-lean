## Remaining gap / next step

The missing model field is an admission invariant on the verifier:
`SigVerifier` is an unconstrained function, while
`GossipSignature.Valid` (`bytes.size = 64`) is only a predicate on the
message.  A production admission path must use `lengthChecked` in
`acceptChannelUpdate`/`applyGossipChecked`, or require `LengthRespecting` at
the store boundary.  Applying that guard changes wave-A model semantics
(`applyGossipChecked_update_eq` only assumes `signatureValid`), so it is left
to the integrator; this module supplies the reusable guard, the conditional
theorems, and the proved counterexample without editing the model.
