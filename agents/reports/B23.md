## 4. What remains open, and the next smallest step

1. **HMAC unforgeability is not proved.**  `onion_openLayer_verified` is
   only the mechanical implication "accepted ⇒ verifier returned `true`".
   `onion_openLayer_hmac_eq_tag` and `onion_openLayer_authentic` add an
   explicit hypothesis, `VerifierBindsTag`; this hypothesis is *not*
   derived from `OnionInterface.hmacBinding`, which is an uninterpreted
   `Prop`.  Nothing here claims onion authenticity against an active
   attacker.  *Next smallest step:* instantiate `OnionInterface` from a
   concrete `Crypto.Model` HMAC and prove `VerifierBindsTag` from the named
   C8 property (or add a `verifyHmac_sound` field to the interface and
   restate the theorem).
2. **The model's failure packet omits `pad_len`.**  `OnionError.packetSize`
   is 290 for data ≤ 256; BOLT 4's exact field order (and LDK's
   `FAILURE_PACKET_BASE_LEN = 32 + 2 + 2 + 2`) makes it 292.  The report
   and the Lean lemmas state both and prove the 2-byte difference; the
   model itself was not edited (wave-A file).  *Next smallest step:* add a
   `padLen : Nat` field (or a separate spec-sized structure) to the proof
   module and prove the 32768 bound with data + pad + attribution lengths
   as parameters.
3. **Error origin is not authenticated.**  `OnionError` has no origin
   field, so `AttributedError`/`recordHopError` are a local bookkeeping
   wrapper.  `recordHopError_origin_mem_routeNodes` proves the recorded
   node is in the route, but no signature or MAC binds it.  *Next smallest
   step:* add an abstract `ErrorOriginAuth` predicate and a conditional
   theorem `recordHopError_origin_authenticated`.
4. **Sphinx construction is structural only.**  `sealLayers` uses empty
   ciphertexts/HMACs; there is no ChaCha20-Poly1305, HKDF, ECDH, filler,
   BigSize, or TLV encoding.  `sealRoute` uses the route's single
   `amountMsat` for every hop, so it is not a fee-adjusted per-hop payload
   construction.  No privacy, unlinkability, or size-hiding claim is made.
5. **`encodedSize` is not the wire size.**  `wireSize` is a constant 1366;
   `encodedSize` counts only the terminal payload, encoded layers, and a
   version byte.  The bound `encodedSize_le_packet_max` is conditional on
   fitting the 1300-byte `hop_payloads` budget and is not a proof that
   arbitrary layer lists fit.
6. **Truncation is out of scope.**  Failure data larger than 256 bytes,
   return packets larger than 32768 bytes, and the BOLT 4 truncation rule
   are not modelled; the bounds are stated under `data.size ≤ 256`.
