## 1. Result

The old target `LnLean.Protocol.Handshake.funding_signed_valid` is only the
`iff` characterization

```lean
fundingSignedValid M fundingKey fundingTx m ↔
  wireSigOK m.signature.bytes = true ∧
    fundingSignedVerifies M fundingKey fundingTx m
```

and it leaves both halves of the English claim implicit: no signing
completeness, no key attribution. This lane adds the missing faithful
conditional contract and proves:

1. an **honest/counterparty** `funding_signed` record, produced by signing the
   funding-tagged transaction under a key, is `fundingSignedValid` over that
   transaction;
2. under an explicit **key-binding** hypothesis, any key that also validates
   the record is the producing key;
3. under C3 (the model's `ecdsa_eufCma` field), any transaction that also
   validates the record is the producing transaction;
4. the record is `wellFormed` when its channel id is 32 bytes;
5. C3 alone does **not** give key attribution: a full `PrimitiveModel`
   satisfying `EufCma` is constructed on which one wire-shaped
   `funding_signed` validates under two distinct keys.

The result is conditional. It does not claim that C3/EUF-CMA alone proves the
literal sentence, and it does not claim computational unforgeability.

## 2. Exact missing model fields

The following are missing from the current model, and are stated explicitly in
the module docstring and in the types below.

* `LnLean.Protocol.FundingSigned` is `{ channelId, signature }`. It has **no
  `fundingPubKey : PubKey`** (or equivalent `signerKey`) field and **no
  `fundingTx : ByteArray`** / signed-txid field.
* `HandshakeState` stores only boolean milestones, and
  `handshakeStep`'s `sendFundingSigned` / `recvFundingSigned` events carry no
  `FundingSigned` payload, so no key can be attributed to a record.
* `LnLean.Crypto.PrimitiveModel` has **no `ecdsaSign`** operation and **no
  signing-correctness law**. `EufCma` is message binding for a fixed key and
  signature; it cannot produce a signature.

The new predicates supply these missing pieces as explicit hypotheses rather
than adding fields to the shared wire types (which this lane may not edit):

* `FundingSigningLaw M` — signing function, correctness law, wire-shape law.
* `FundingSignedProducedBy law m fundingKey fundingTx` — the attribution
  certificate: `m.signature = law.sign fundingKey (fundingTag ++ fundingTx)`.
* `LnLean.Crypto.KeyBinding M.ecdsaVerify` — the independent key-attribution
  hypothesis (already defined in `LnLean/Proofs/Crypto/EcdsaProps.lean`; C3
  does not imply it).

## 3. Exact signatures

File: `LnLean/Proofs/ProtocolSigningTargets.lean`, all declarations in
namespace `LnLean.Protocol.Handshake`.

```lean
structure FundingSigningLaw (M : PrimitiveModel) where
  sign : PubKey → ByteArray → EcdsaSig
  verifies : ∀ (pk : PubKey) (msg : ByteArray),
    M.ecdsaVerify pk msg (sign pk msg) = true
  wire : ∀ (pk : PubKey) (msg : ByteArray),
    wireSigOK (sign pk msg).bytes = true

def FundingSignedProducedBy {M : PrimitiveModel} (law : FundingSigningLaw M)
    (m : FundingSigned) (fundingKey : PubKey) (fundingTx : ByteArray) : Prop :=
  m.signature = law.sign fundingKey (fundingTag ++ fundingTx)

def honestFundingSigned {M : PrimitiveModel} (law : FundingSigningLaw M)
    (channelId : ChannelId) (fundingKey : PubKey)
    (fundingTx : ByteArray) : FundingSigned

theorem honestFundingSigned_produced {M : PrimitiveModel}
    (law : FundingSigningLaw M) (channelId : ChannelId)
    (fundingKey : PubKey) (fundingTx : ByteArray) :
    FundingSignedProducedBy law
      (honestFundingSigned law channelId fundingKey fundingTx)
      fundingKey fundingTx

theorem funding_signed_valid_of_produced {M : PrimitiveModel}
    (law : FundingSigningLaw M) {m : FundingSigned} {fundingKey : PubKey}
    {fundingTx : ByteArray}
    (hprod : FundingSignedProducedBy law m fundingKey fundingTx) :
    LnLean.Proofs.WaveE.E19.fundingSignedValid M fundingKey fundingTx m

theorem funding_signed_valid_of_honest {M : PrimitiveModel}
    (law : FundingSigningLaw M) (channelId : ChannelId)
    (fundingKey : PubKey) (fundingTx : ByteArray) :
    LnLean.Proofs.WaveE.E19.fundingSignedValid M fundingKey fundingTx
      (honestFundingSigned law channelId fundingKey fundingTx)

theorem funding_signed_attribution {M : PrimitiveModel}
    (law : FundingSigningLaw M) (hkb : KeyBinding M.ecdsaVerify)
    {m : FundingSigned} {fundingKey fundingKey' : PubKey}
    {fundingTx : ByteArray}
    (hprod : FundingSignedProducedBy law m fundingKey fundingTx)
    (hvalid : LnLean.Proofs.WaveE.E19.fundingSignedValid M fundingKey' fundingTx m) :
    fundingKey' = fundingKey

theorem funding_signed_binds_tx_of_produced {M : PrimitiveModel}
    (law : FundingSigningLaw M) {m : FundingSigned} {fundingKey : PubKey}
    {fundingTx fundingTx' : ByteArray}
    (hprod : FundingSignedProducedBy law m fundingKey fundingTx)
    (hvalid : LnLean.Proofs.WaveE.E19.fundingSignedValid M fundingKey fundingTx' m) :
    fundingTx' = fundingTx

theorem funding_signed_signing_contract {M : PrimitiveModel}
    (law : FundingSigningLaw M) (hkb : KeyBinding M.ecdsaVerify)
    (channelId : ChannelId) (fundingKey : PubKey) (fundingTx : ByteArray) :
    let m := honestFundingSigned law channelId fundingKey fundingTx
    wireSigOK m.signature.bytes = true ∧
      LnLean.Proofs.WaveE.E19.fundingSignedValid M fundingKey fundingTx m ∧
      (∀ fundingKey' : PubKey,
        LnLean.Proofs.WaveE.E19.fundingSignedValid M fundingKey' fundingTx m →
          fundingKey' = fundingKey) ∧
      (∀ fundingTx' : ByteArray,
        LnLean.Proofs.WaveE.E19.fundingSignedValid M fundingKey fundingTx' m →
          fundingTx' = fundingTx)

theorem counterparty_funding_signed_signing_contract {M : PrimitiveModel}
    (law : FundingSigningLaw M) (hkb : KeyBinding M.ecdsaVerify)
    (c : Channel) (channelId : ChannelId) (fundingTx : ByteArray) :
    let m := honestFundingSigned law channelId
      (LnLean.Proofs.WaveE.E06.counterpartyFundingKey c) fundingTx
    wireSigOK m.signature.bytes = true ∧
      LnLean.Proofs.WaveE.E19.fundingSignedValid M
        (LnLean.Proofs.WaveE.E06.counterpartyFundingKey c) fundingTx m ∧
      (∀ fundingKey' : PubKey,
        LnLean.Proofs.WaveE.E19.fundingSignedValid M fundingKey' fundingTx m →
          fundingKey' = LnLean.Proofs.WaveE.E06.counterpartyFundingKey c) ∧
      (∀ fundingTx' : ByteArray,
        LnLean.Proofs.WaveE.E19.fundingSignedValid M
          (LnLean.Proofs.WaveE.E06.counterpartyFundingKey c) fundingTx' m →
          fundingTx' = fundingTx)

theorem honestFundingSigned_wellFormed {M : PrimitiveModel}
    (law : FundingSigningLaw M) (channelId : ChannelId)
    (hcid : channelId.Valid) (fundingKey : PubKey) (fundingTx : ByteArray) :
    LnLean.Protocol.wellFormed
      (LnLean.Protocol.Msg.fundingSigned
        (honestFundingSigned law channelId fundingKey fundingTx))

theorem funding_signed_attribution_not_from_eufCma (M₀ : PrimitiveModel) :
    ∃ (M : PrimitiveModel) (fundingTx : ByteArray) (m : FundingSigned)
      (k₁ k₂ : PubKey),
      k₁ ≠ k₂ ∧
        EufCma M.ecdsaVerify ∧
        LnLean.Proofs.WaveE.E19.fundingSignedValid M k₁ fundingTx m ∧
        LnLean.Proofs.WaveE.E19.fundingSignedValid M k₂ fundingTx m
```

## 4. Proof strategy

* **Completeness.** `fundingSignedValid` is `verifyFundingChecked`, i.e.
  `wireSigOK sig.bytes && verifyFunding M key tx sig`. Unfold the `iff`, use
  `FundingSigningLaw.wire` for the parser half, then rewrite the produced
  signature equation and use `FundingSigningLaw.verifies` for
  `ecdsaVerify key (fundingTag ++ tx) sig`.
* **Attribution.** `fundingSignedValid` soundness gives acceptance under the
  claimed key. `FundingSigningLaw.verifies` gives acceptance under the
  producing key. `KeyBinding` on the tagged funding message forces the two
  public keys equal.
* **Transaction binding.** The produced record is valid over its own
  transaction by completeness; a second validation over `fundingTx'` is
  compared by `WaveE.E19.waveE_e19_funding_signed_valid_binds_tx`, which uses
  the model's `ecdsa_eufCma` field (C3) and prefix cancellation on
  `fundingTag ++ ·`.
* **Well-formedness.** E19's exact `wellFormed` characterization reduces to
  the channel id width and `sig.bytes.size ≤ 73`; the latter follows from the
  signing law's `wireSigOK` and `wireSigOK_size`.
* **Negative result.** `singleMessageEcdsaModel M₀ d₀` copies every primitive
  of `M₀` except `ecdsaVerify := singleMessageVerify d₀`, which accepts exactly
  the fixed tagged message and ignores key and signature. It re-proves
  `ecdsa_eufCma` via `LnLean.Crypto.eufCma_singleMessage`, so the structure is
  a legal `PrimitiveModel`. The record uses a 64-byte zero signature; both
  chosen keys accept the same tagged transaction, demonstrating that C3 alone
  cannot give key attribution.

This module reuses E19's checked predicate and E06's `counterpartyFundingKey`;
it does not duplicate or weaken either.

## 7. Blockers / residual gaps

* `FundingSigned` still has no key or funding-transaction field, and
  `HandshakeState` still carries no message payload. The contract is therefore
  parameterized by `FundingSignedProducedBy`, not proved from the wire record
  alone. A future model change could add `fundingPubKey` and
  `signedFundingTx` (or the BOLT 3 txid) to the channel context, after which
  `funding_signed_valid_of_produced` could be applied without the certificate
  parameter.
* `FundingSigningLaw.sign` is keyed directly by `PubKey` because the model has
  no secret-key type. This is the same explicit idealization as
  `WaveE.E06.SigningCompleteness`; it is not a claim that a public key can
  sign, and no computational unforgeability is claimed.
* `KeyBinding` remains an explicit hypothesis. The negative theorem in this
  module (and `LnLean.Crypto.eufCma_not_keyBinding`) shows it is not a
  consequence of the `EufCma` field.
* The BOLT 3 sighash/txid construction is still absent; `fundingTx` is an
  explicit byte string.
