## Verdict

The catalog row `LN-RT-006` does **not** currently name a theorem. Its target
`LnLean.Routing.Gossip.announcement_valid` is a `def` alias declared in
`LnLean/Proofs/WaveD/D27.lean:444` for
`LnLean.Proofs.WaveD.D27.announcementValid`, which in turn is the four-way
signature predicate. The unconditional English claim is false for the raw
store step and is not even well posed for the raw graph:

* raw `applyGossip` stores a `channel_announcement` with **no** signature
  check (exact membership theorem and counterexample below);
* `GossipState` has no graph, and `GossipNetwork.views` is an unconstrained
  field; `GossipNetwork.applyMessage` never materialises a view from an
  admitted announcement. A raw `GossipNetwork` can therefore have a graph
  edge with an empty announcement list.

This lane adds a faithful **admission model** (`admitGossip`, `Reachable`) in
which a channel announcement enters the store and the graph only through a
signature gate, and proves:

> every edge of the graph of every reachable admitted network is backed by a
> stored announcement whose four BOLT 7 signatures verify.

It also keeps the raw/checked distinction exact, proves the raw-model
counterexamples, and keeps the G19 key-attribution gap explicit. There is no
`sorry`, `axiom`, `admit`, `native_decide`, `unsafe`, or
`@[implemented_by]`.

## 2. Exact raw-store gap

Raw wave-A membership has no validity conjunct:

```lean
theorem raw_applyGossip_announcement_mem_iff (s : GossipState)
    (a₀ a : ChannelAnnellation) :
    a ∈ (applyGossip s (.channelAnnouncement a₀)).announcements ↔
      a = a₀ ∨ a ∈ s.announcements
```

Consequences (all proved):

```lean
theorem raw_applyGossip_admits_invalid_announcement
    (verify : SigVerifier) (s : GossipState) (a : ChannelAnnellation)
    (_h : ¬ announcementValid verify a) :
    a ∈ (applyGossip s (.channelAnnouncement a)).announcements

theorem raw_store_not_filtered :
    ∃ (verify : SigVerifier) (s : GossipState) (a : ChannelAnnellation),
      a ∈ (applyGossip s (.channelAnnouncement a)).announcements ∧
        ¬ announcementValid verify a

theorem raw_store_invariant_not_preserved :
    ∃ (verify : SigVerifier) (s : GossipState) (a : ChannelAnnellation),
      ¬ StoreAnnouncementsValid verify
        (applyGossip s (.channelAnnouncement a))
```

The witness verifier rejects every signature, so the gap is not an artefact of
an unusually weak witness: even a verifier that rejects everything is ignored
by the raw store step.

## 3. Exact checked-store characterization

```lean
theorem applyGossipChecked_announcement_mem_iff (verify : SigVerifier)
    (s : GossipState) (a₀ a : ChannelAnnellation) :
    a ∈ (applyGossipChecked verify s (.channelAnnouncement a₀)).announcements ↔
      (a = a₀ ∧ announcementValid verify a₀) ∨ a ∈ s.announcements

theorem applyGossipChecked_preserves_store (verify : SigVerifier)
    (s : GossipState) (m : GossipMessage)
    (h : StoreAnnouncementsValid verify s) :
    StoreAnnouncementsValid verify (applyGossipChecked verify s m)
```

Standalone insertion step:

```lean
noncomputable def admitAnnouncement (verify : SigVerifier) (s : GossipState)
    (a : ChannelAnnellation) : GossipState :=
  if a.signaturesValid verify then applyGossip s (.channelAnnouncement a) else s

theorem admitAnnouncement_stores_iff (verify : SigVerifier) (s : GossipState)
    (a : ChannelAnnellation) :
    (admitAnnouncement verify s a).announcements = a :: s.announcements ↔
      announcementValid verify a

theorem admitAnnouncement_changes_iff (verify : SigVerifier) (s : GossipState)
    (a : ChannelAnnellation) :
    admitAnnouncement verify s a ≠ s ↔ announcementValid verify a
```

`admitAnnouncement_stores_iff` is exact in both directions: insertion at the
head happens **iff** the announcement verifies, and a successful insertion
strictly grows the list (so the reverse direction is not vacuous).

## 4. Filtering at graph materialisation

```lean
noncomputable def announcementGraph (verify : SigVerifier)
    (l : List ChannelAnnellation) : Graph :=
  viewGraph (l.filterMap (admittedView verify))

theorem mem_announcementGraph_edges_iff (verify : SigVerifier)
    (l : List ChannelAnnellation) (e : ChannelEdge) :
    e ∈ (announcementGraph verify l).edges ↔
      ∃ a ∈ l, a.signaturesValid verify ∧
        e = (ChannelBinding.ofAnnouncement a).edge

theorem announcementGraph_only_valid (verify : SigVerifier)
    (l : List ChannelAnnellation) :
    ∀ e ∈ (announcementGraph verify l).edges,
      ∃ a ∈ l, announcementValid verify a ∧
        e.shortChannelId = a.shortChannelId

theorem announcementGraph_edges_eq_nil_of_all_invalid (verify : SigVerifier)
    (l : List ChannelAnnellation)
    (h : ∀ a ∈ l, ¬ a.signaturesValid verify) :
    (announcementGraph verify l).edges = []
```

This is unconditional because the projection is *defined* to drop unverified
announcements. It is not a claim that wave-A `applyGossip` or the raw
`GossipNetwork.views` field already filters.

## 5. Network admission model and headline theorem

`admitGossip` is the explicit admission transition:

* `channel_announcement a`: if `a.signaturesValid verify`, insert `a` into the
  checked store **and** prepend `admittedChannelView a` to the views;
  otherwise the state is unchanged (so no store entry, no graph edge);
* `channel_update u`: if `u.signatureValid verify`, checked store insertion
  plus the per-view timestamp/disable replacement; otherwise unchanged;
* `node_announcement n`: if `n.signatureValid verify`, checked store
  insertion; no routing edge.

The store component is pinned to the existing checked step:

```lean
theorem admitGossip_gossip_eq (verify : SigVerifier) (ns : GossipNetwork)
    (m : GossipMessage) :
    (admitGossip verify ns m).gossip =
      applyGossipChecked verify ns.gossip m

theorem admitGossip_announcement_mem_iff (verify : SigVerifier)
    (ns : GossipNetwork) (a₀ a : ChannelAnnellation) :
    a ∈ (admitGossip verify ns (.channelAnnouncement a₀)).gossip.announcements ↔
      (a = a₀ ∧ announcementValid verify a₀) ∨
        a ∈ ns.gossip.announcements
```

Reachability is structural, not a free hypothesis on an arbitrary network:

```lean
inductive Reachable (verify : SigVerifier) : GossipNetwork → Prop
  | empty : Reachable verify { gossip := ⟨[], [], []⟩, views := [] }
  | step {ns : GossipNetwork} {m : GossipMessage} :
      Reachable verify ns → Reachable verify (admitGossip verify ns m)

def ViewsBacked (verify : SigVerifier) (ns : GossipNetwork) : Prop :=
  ∀ v ∈ ns.views, ∃ a ∈ ns.gossip.announcements,
    a.signaturesValid verify ∧ v.scid = a.shortChannelId ∧
      v.node1 = a.node1 ∧ v.node2 = a.node2 ∧
        v.capacitySat = a.capacitySat
```

Headline exact target:

```lean
theorem gossip_graph_only_valid_announcements (verify : SigVerifier)
    (ns : GossipNetwork) (h : Reachable verify ns) :
    ∀ e ∈ ns.graph.edges,
      ∃ a ∈ ns.gossip.announcements,
        announcementValid verify a ∧ e.shortChannelId = a.shortChannelId
```

Supporting exact statements:

```lean
theorem reachable_store_valid {verify : SigVerifier} {ns : GossipNetwork}
    (h : Reachable verify ns) : StoreAnnouncementsValid verify ns.gossip

theorem reachable_views_backed {verify : SigVerifier} {ns : GossipNetwork}
    (h : Reachable verify ns) : ViewsBacked verify ns

theorem reachable_stored_announcement_valid {verify : SigVerifier}
    {ns : GossipNetwork} (h : Reachable verify ns) {a : ChannelAnnellation}
    (ha : a ∈ ns.gossip.announcements) : announcementValid verify a

theorem gossip_graph_edges_backed (verify : SigVerifier)
    (ns : GossipNetwork) (h : Reachable verify ns) :
    ∀ e ∈ ns.graph.edges, ∃ a ∈ ns.gossip.announcements,
      announcementValid verify a ∧ e.shortChannelId = a.shortChannelId ∧
        e.node1 = a.node1 ∧ e.node2 = a.node2 ∧
          e.capacitySat = a.capacitySat
```

Non-vacuity and the graph gap:

```lean
theorem admitGossip_announcement_graph_edges (verify : SigVerifier)
    (ns : GossipNetwork) (a : ChannelAnnellation)
    (h : a.signaturesValid verify) :
    (admitGossip verify ns (.channelAnnouncement a)).graph.edges =
      (ChannelBinding.ofAnnouncement a).edge :: ns.graph.edges

theorem reachable_graph_nonempty :
    ∃ (verify : SigVerifier) (ns : GossipNetwork),
      Reachable verify ns ∧ ns.graph.edges ≠ []

theorem arbitrary_network_edge_without_announcement :
    ∃ ns : GossipNetwork, ns.gossip.announcements = [] ∧ ns.graph.edges ≠ []
```

`reachable_graph_nonempty` uses a concrete verifying announcement, so the
headline theorem is not vacuous: there is a reachable state with a real edge.
`arbitrary_network_edge_without_announcement` shows why `Reachable` cannot be
dropped: an arbitrary `GossipNetwork` has a graph edge with no announcement at
all.

## 6. G19 key-attribution gap (kept explicit)

The G19 audit (`agents/reports/G19.md`, target `LN-GOSSIP-001`) is about
`channel_update` signing-key attribution. It remains a separate admission gap;
it is **not** implied by `signaturesValid`.

```lean
theorem g19_signature_only_gap :
    ∃ (verify : SigVerifier) (s : GossipState) (u : ChannelUpdate),
      acceptChannelUpdate verify s u ≠ s ∧ ¬ updateKeyAnnounced s u
```

The witness is an always-accepting verifier, an empty store, and an update
whose key was never announced. Signature-only acceptance changes the store.

Required extra check, and its sufficiency:

```lean
noncomputable def admitUpdateAttributed (verify : SigVerifier) (s : GossipState)
    (u : ChannelUpdate) : GossipState :=
  if u.signatureValid verify ∧ updateKeyAnnounced s u then s.applyUpdate u else s

theorem admitUpdateAttributed_change_requires (verify : SigVerifier)
    (s : GossipState) (u : ChannelUpdate)
    (h : admitUpdateAttributed verify s u ≠ s) :
    u.signatureValid verify ∧ updateKeyAnnounced s u

theorem g19_attributed_admission_rejects :
    ∃ (verify : SigVerifier) (s : GossipState) (u : ChannelUpdate),
      ¬ updateKeyAnnounced s u ∧ admitUpdateAttributed verify s u = s
```

Announcement side of the same seam: `NodeId` (opaque graph index) and `PubKey`
(BOLT 7 wire key) are independent fields, and wave A has no map between them.

```lean
def KeyAttribution (nodeKeyOf : NodeId → PubKey) (a : ChannelAnnellation) : Prop :=
  nodeKeyOf a.node1 = a.nodeKey1 ∧ nodeKeyOf a.node2 = a.nodeKey2

theorem signature_valid_not_key_attribution :
    ∃ (verify : SigVerifier) (nodeKeyOf : NodeId → PubKey)
      (a : ChannelAnnellation),
      a.signaturesValid verify ∧ ¬ KeyAttribution nodeKeyOf a
```

The catalog statement is about signature validity only. It must not be read as
"the graph node is the owner of the verifying key", and it must not be read as
"an accepted update is signed by the announced node key". Both are separate
admission checks.

Scope caveats that must accompany the row (do not drop them):

1. The graph theorem is over `Reachable verify ns` states built by the
   signature-gated `admitGossip` transition. It is not a theorem about an
   arbitrary `GossipNetwork`; `arbitrary_network_edge_without_announcement`
   is the counterexample.
2. Raw `applyGossip` is unfiltered (`raw_store_not_filtered`,
   `raw_store_invariant_not_preserved`). Any future use of raw
   `applyGossip` for announcement insertion re-opens the gap.
3. `SigVerifier` is abstract. Only the four verifier equations are claimed;
   unforgeability, key ownership, chain-hash filtering, UTXO confirmation, and
   gossip rate limits remain outside the model (assumptions C3/C4/C8 and the
   BOLT 7 admission rules).
4. G19 key attribution is separate: the provenance theorem does not claim
   `updateKeyAnnounced`, `KeyAttribution`, or that a graph `NodeId` is a BOLT 7
   `node_id`.
5. `announcementGraph_only_valid` is unconditional only for the explicitly
   filtered materialisation projection; it does not say the wave-A graph was
   already filtered.

Do **not** promote the existing `def` target by itself; a `def` target cannot
satisfy the theorem/lemma rule and would continue to look "proved" only if the
checker rule were weakened.
