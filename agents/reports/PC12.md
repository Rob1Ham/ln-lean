| `accepts_intersection_of_accepts` | proved | none (reuses `accepts_iff_no_unknown_required`, `intersection_requires`) |

The proof rewrites acceptance on both hypotheses and the goal to the
pointwise rule “every unknown feature has its even bit clear”.  At an unknown
feature `n`, both `f.requires n` and `g.requires n` are `false`, hence
`(intersection f g).requires n = (f.requires n && g.requires n) = false`.
This is exactly the mission's key fact: `Bool.and` cannot turn a cleared
required bit into a set one.  No statement, definition, import, or namespace
was changed.
