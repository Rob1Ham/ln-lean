## 4. What remains open and the next smallest step

1. **No joint `PeerState`/`Channel` transition.**  `PeerState` has no
   `Channel`, and there is no `Msg → ProtocolEvent` map, so
   `reconnect_resend_completes_lockin` states the retention half and the
   channel-step half separately.  *Next step:* add a wave-B bridge
   `MsgKind.channelReady ↦ ProtocolEvent.fundingLocked` with a
   `PeerState`+`Channel` product step, then compose the two halves.
2. **`NoLoss` is stronger than BOLT 2 fairness.**  It forbids drops rather
   than requiring retransmission.  The model cannot state "lossy but fair"
   because `LossyLink` has no fairness predicate.  *Next step:* define a
   fair-lossy scheduler over `LossyLink` and prove that retained messages are
   redelivered; use `reconnect_preserves_channelReady` for the buffer half.
3. **HTLC liveness is trigger-conditional.**  `HTLCTrigger`/`HonestTimer`
   are hypotheses; no wall clock, no tip progression, and `HTLCState` has no
   `timedOut` tag (timeout is `removed`).  *Next step:* add a monotone tip
   model and a `timedOut` state, then derive `HTLCTrigger.expired` from
   tip progress and the CLTV bound.
4. **Commitment-round liveness is absent.**  `AwaitingRemoteRevoke` and the
   `commitment_signed`/`revoke_and_ack` queue are not modelled in wave A, so
   no theorem claims a commitment round completes.  *Next step:* model the
   deferred-update queue and prove each queued update is eventually signed.
5. **Catalog references not satisfied.**  `LnLean/Proofs/Obligations.lean`
   rows `LN-SEC-005` and `LN-SEC-006` target
   `LnLean.Proofs.Liveness.penalty_economical` and
   `LnLean.Proofs.Liveness.watchtower_bridge`.  Those declarations are **not
   in this file**: expressing them needs `LnLean.Security.Invariants` (or L1
   penalty predicates), which is outside B31's import allowlist.  Integrator
   action: either allow that import in a follow-up B-file or repoint the two
   catalog rows.
6. **`check.sh` is currently red on another agent's file**
   (`LnLean/Proofs/Routing/RouteBlindingProps.lean`, unmarked `sorry`).  This
   module is unaffected.
