results, then emits one `#print axioms <fully-qualified-name>` command per
theorem. The full output was captured with:

```bash
export PATH=/dev/shm/btc/elan/toolchains/leanprover--lean4---v4.35.0/bin:$PATH
cd /home/ubuntu/ln-lean-phasec3
flock -w 900 /tmp/ln-build.lock lake env lean LnLean/Proofs/PhaseC3/AxiomAudit.lean
```

the table below reports the exact sets after joining those continuation
lines. The `#print axioms` output itself is the machine-checked evidence:
each line is emitted by Lean's kernel-level dependency printer, not by
hand-written metadata.
