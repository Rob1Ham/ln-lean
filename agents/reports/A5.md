## 4. What remains open

* `msgLength_le_65535` is obtained by projecting `wellFormed`'s first
  conjunct.  A stronger next step is a constructor-by-constructor derivation
  of the length bound from the BOLT field widths, independent of the
  `wellFormed` predicate.  The concrete lemmas `msgLength_acceptChannel`,
  `msgLength_updateAddHtlc`, `pong_reply_bounded`, and `ping_bounded` are the
  first instances of that direction.
* `open_channel` is not in `Msg`.  The handshake's `sendAcceptChannel` guard
  abstracts away the environment event that would correspond to receiving
  it.  A next step is an `open_channel` payload structure plus an explicit
  environment receive transition.
* `Peer.receive` does not require `channel_ready` before `update_*` /
  `commitment_signed`; only the handshake order is enforced.  BOLT 2's
  normal-operation ordering (updates after both `channel_ready`) is an open
  refinement.  `shutdown` is the exception that BOLT 2 allows before
  `channel_ready` (`02-peer-protocol.md:2152`).
* `resend` exposes retained copies but does not schedule retransmission.
  BOLT 2's `channel_reestablish` decision tree (`02-peer-protocol.md:3470-3570`)
  is not implemented; the four counters and their monotonicity are.
* `wellFormed` checks only signature byte length, not DER structure or
  validity.  Signature verification remains assumption C3.
* No authentication theorem is claimed.  `TransportState.up` is a local
  willingness flag; peer identity is a label.  Noise is the interface named
  in `docs/ASSUMPTIONS.md` §3.
* No liveness: `LossyLink` permits dropping every message forever.
* `ReestablishFields` stores a `ByteArray` secret and a `PubKey` point, but
  does not relate them by the per-commitment-secret derivation of BOLT 3.
* The peer box's `refs/` directory contained only `refs/PINNED.md` at the
  time of this work, so the BOLT/rust-lightning anchors above were verified
  against temporary clones at exactly the pinned commits
  (`/tmp/opencode/anchor/bolts` at `1aadb719...` and
  `/tmp/opencode/anchor/rl` at `fe49009...`).  No file under `refs/` was
  modified.

Next smallest step: add `lnLean.Protocol.ChannelReestablish`-style
constructor-by-constructor length lemmas (starting with `accept_channel`,
`funding_created`, and `commitment_signed`) and then an `open_channel`
payload plus its environment transition.
