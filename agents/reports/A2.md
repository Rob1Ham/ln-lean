## 4. What remains open, and the next smallest step

1. **TLV parser round trip.** `parseRecord` and `decodeTLV` are total
   `Option`-valued reference implementations, but no theorem proves
   `decodeTLV (encodeTLV s) = some s`. The docstring and the module header
   record this as an intentional gap. *Next smallest step:* prove the
   single-record lemma
   `parseRecord (bytesToList (TLVRecord.encode r)) = some (r, [])`
   (using `decode_encode` for the two BigSize fields and list `take/drop`
   lemmas), then induct over `s.records` under `WellFormed` to obtain the
   stream theorem.
2. **BigSize decoder completeness/canonicality.** We prove
   `decode (encode n) = some (n, size)` for all `n < 2^64`, and the decoder
   implementation rejects non-minimal `0xfd`/`0xfe`/`0xff` encodings. We do
   not prove the converse (`decode b = some (n, k) → b = encode n`) or a
   general canonicality theorem. *Next smallest step:* prove
   `decode_sound` for each tag case, starting with `decodePayload_fd`.
3. **Message extension contents.** `Message.lean` models only the
   arithmetic rule that a full 65535-byte message has zero extension
   capacity; it does not parse or append an actual TLV extension. The
   abstract frame includes a plaintext length header, while on the wire the
   two-byte length is inside the Noise-encrypted header. *Next smallest
   step:* add an optional `extension : Option TLVStream` to a separate
   `FramedMessage` type and prove its encoded size equals
   `messageSize + extension size`, keeping `WireMessage` unchanged.
4. **Noise handshake and rekeying.** Only post-handshake transport is
   modelled. There is no `Noise_XK` transcript, ephemeral key generation,
   ECDH transcript hashing, HKDF chaining-key derivation, 1000-message
   rekey rule, padding, or Poly1305 tag bytes. *Next smallest step:* define
   an abstract handshake state machine with a `Finished` predicate and prove
   that `transportEncrypt` is available only after `Finished`; the concrete
   transcript remains an interface.
5. **Signature tags are stand-ins.** `fundingTag`, `commitmentTag`, and
   `closeTag` are short ASCII tags, not the BIP-340 tagged-hash byte
   layouts. `EufCma` models message binding (one signature cannot verify
   for two messages), not the full EUF-CMA game with an adversary and a
   signing oracle. *Next smallest step:* parameterize verification by a
   `TaggedHash` operation and derive the current three tags as instances;
   keep the message-binding theorem conditional on the same field.
6. **Cryptographic assumptions are exact algebraic laws.** `CollisionResistant`
   is injectivity on 32-byte inputs, which is stronger than computational
   collision resistance; `PreimageResistant` is injectivity on all byte
   strings and is currently not consumed by a theorem. `AeadIndCca` is
   correctness plus ciphertext-determined plaintext, not an IND-CCA game.
   No reduction to a computational assumption is claimed. *Next smallest
   step:* either use `PreimageResistant` in a stated hiding/commitment
   property or remove it from the interface in the integration pass; do not
   leave an unused assumption presented as a proved fact.
7. **Unused primitive fields.** `hash160`, `ecdh`, and `hkdf` are present
   in `PrimitiveModel` with size facts where applicable, but no
   collision-resistance, CDH, or PRF field is stated for them. This is
   honest scope: no downstream A2 theorem needs those properties.
   *Next smallest step:* add `hash160_collisionResistant`,
   `ecdh_cdh`, and `hkdf_prf` as `Prop` fields only when a consumer states
   the corresponding conditional theorem.
8. **Anchors.** The local clones are present and the cited paths/lines

   Content was manually spot-checked for the BigSize, message-type,
   signature, Noise, and TLV macro anchors. The script checks existence,
   not semantic agreement, so an integrator should re-read any anchor if a
   module claim changes.
