## Newly discovered gap: the existing `L1ScriptBridge` is vacuous

`LnLean.Channel.L1ScriptBridge.noDoubleSpend` is

```lean
∀ (t u : Tx) (o : OutPoint),
  Spends t o → Spends u o → confirms t → ¬ confirms u
```

The quantification includes `u = t`.  Hence `bridge_not_confirms_spending`
proves that a transaction accepted by any `L1ScriptBridge` cannot spend *any*
outpoint at all, and `no_bridge_confirms_penalty` proves that no existing
bridge can confirm a penalty transaction (`p.toTx` always spends
`p.inputLocal`).  The existing theorem
`punished_not_breacher_spendable` remains true but is vacuous: its
confirmation premise is unsatisfiable.

The repaired, non-vacuous interface is `L1ScriptBridgeDistinct`, whose
`noDoubleSpend` field is restricted by `t ≠ u`.  `singletonBridge` witnesses
that this interface can confirm a transaction, and
`exists_distinctBridge_confirms_penalty` witnesses confirmation of any given
penalty transaction.  The strongest true conditional form is
`punishable_exclusive_spend_distinct`: a timely confirmed valid penalty is the
*unique* confirmed spend of either contested outpoint.
