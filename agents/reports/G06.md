## Reasoning
Target 11 is a genuine near-tie: both files are sorry-free, compiled, and faithful, and both mechanize the same necessary residual/cover conditions. I choose D11 narrowly because (a) its central bound uses the minimal BOLT conservation equation `totalOutputValue + fee = funding`, while E11's equality theorem assumes the stronger residual+fit pair (D11 also proves a residual-based ≤ variant), (b) D11 proves per-output bounds, (c) D11 proves the model's own `commitmentPairOfBalances` safe with anchors off, which E11 does not, and (d) D11's anchored failure is computed concretely (2,660 sat against a 2,000 sat funding value). E11 is better on modular group-sum lemmas, the exact `outputs + fee = funding` equality, the `Nat`-to-`Int` no-underflow lemma, and a parameterized anchor counterexample; those are worth porting rather than retaining the whole file. This is why target 11 is medium confidence, not high. Neither file proves the anchored case; both correctly refute it.

Target 12 is not close. D12 has the same zero-sorry/artifact evidence but much stronger catalog fidelity: it actually models the script and CLTV tie-break components (as an explicitly external rank), proves the three-level conditional ordering theorem, proves that the model erases the CLTV tie-break, proves the exact dust-present iff, and mechanizes the model-level dust failure. E12 is sound but solves only the value half of "ordered by value then script" and never shows that `commitmentOutputs` emits dust. The larger declaration count in D12 is a consequence of implementing the missing half of the claim, not the reason for the verdict.
