## 3. Proof approach and helper lemmas

Added helpers (both `private`, in the same file):

* `pushUInt32LE_size : (pushUInt32LE n).size = 4` — the fixed-width
  little-endian encoder always emits exactly four payload bytes.
* `pushData_injective_of_size_eq : a.size = b.size → pushData a = pushData b →
  a = b` — cancels the one-byte length prefix of `pushData` when both
  payloads have the same length.

Proof outlines:

1. **`pushScriptNum32_injective`.** Unfold `pushScriptNum32`/`pushData`,
   cancel the identical length prefix (`0x04`) to get
   `pushUInt32LE a = pushUInt32LE b`, then compare the four bytes of
   `pushUInt32LE` via its `data.toList`. Each byte yields a congruence
   `a / 2^(8i) % 256 = b / 2^(8i) % 256` (`0 ≤ i < 4`), and `omega` with
   `a, b < 2^32` reconstructs `a = b`.
2. **`receivedHtlcWitnessScript_cltv_injective`.** Take the `bytes` fields of
   the two equal scripts, unfold the template, right-associate the `++`
   chains, and cancel the common prefix and suffix with
   `ByteArray.append_right_inj` / `ByteArray.append_left_inj`. The remaining
   middle term is `pushScriptNum32 c1 = pushScriptNum32 c2`, which closes by
   `pushScriptNum32_injective`.
3. **`offeredHtlcWitnessScript_paymentHash_injective`.** Same prefix/suffix
   cancellation around the `pushData paymentHash160` occurrence. The
   remaining term is `pushData h1 = pushData h2`, and
   `pushData_injective_of_size_eq` plus `hh1 : h1.size = 20`,
   `hh2 : h2.size = 20` yields `h1 = h2`.
