- Theorems/definitions:
  - `waveD_d08_decode_encode` — the catalog target, exactly
    `LnLean.Wire.BigSize.decode_encode`:

  - `waveD_d08_decode_canonical_encoding` — a canonical `b` that decodes to
    `(v, len)` has `v < 2^64`, `len = b.size`, and `encode v = b`.
  - `waveD_d08_decode_full_canonical` — strong converse for arbitrary bytes:
    if `decode b = some (v, len)` and `len = b.size`, then `v < 2^64` and
    `encode v = b`.  Hence a successful full decode certifies canonicality.
  - `waveD_d08_decode_full_iff` — two-sided characterisation:
    `decode b = some (v, b.size)` iff `v < 2^64`, `b` is canonical, and
    `b = encode v`.
  - `waveD_d08_encode_injective` — `encode` is injective on `uint64`.
  - `waveD_d08_decode_encode_iff` — complete `iff` form of the forward round
    trip.
  - `waveD_d08_decode_encode_length_cases` — the encoded length is `1`, `3`,

  - Digit-uniqueness helpers `waveD_d08_decodeBEList_lt`,

## Remaining gap / next step

The model's `encode : Nat → ByteArray` is total on `Nat`, but the specification
only covers `uint64`.  Outside that range `encode` truncates modulo `2^64`;
`waveD_d08_encode_truncates` proves `encode (2^64)` is the all-zero `0xff`
payload and that `decode` rejects it, so the round trip is genuinely false for
`n ≥ 2^64`.  Nothing further is missing for the catalog claim on `uint64`.
If the catalog later widens the domain to all `Nat`, the correct statement is
the conditional one proved here, with the bound as an explicit hypothesis.
IO/short-read exceptions are outside the model (`decode` returns `Option`);
the short-read cases above cover the branch the model does represent.
