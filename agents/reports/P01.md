## 3. Dry run (exactly one as specified, plus one allowed credential retry)

Attempt A — the prescribed command, verbatim:

```
GIT_ASKPASS=/tmp/ln-askpass.sh GIT_TERMINAL_PROMPT=0 git push --dry-run origin repair/integrated
```
Output:
```
remote: Permission to Rob1Ham/ln-lean.git denied to Rob1Ham.
fatal: unable to access 'https://github.com/Rob1Ham/ln-lean.git/': The requested URL returned error: 403
```
RC = **128** (auth failure).

Root cause (diagnosed read-only, no config writes): `~/.gitconfig` defines GitHub credential helpers
`!gh auth git-credential` and `store --file=/home/ubuntu/.git-credentials`. Credential helpers are consulted
**before** `GIT_ASKPASS`, so the stale helper credential was sent instead of the token file. The token file itself
is good: `GET /user` → 200 (login `Rob1Ham`), `GET /repos/Rob1Ham/ln-lean` → 200 with
`permissions.push = true`, fine-grained token expiring `2026-11-17 02:02:50 UTC`.

Attempt B — single allowed retry, same token, helper list cleared for that one invocation only:

```
GIT_ASKPASS=/tmp/ln-askpass.sh GIT_TERMINAL_PROMPT=0 git -c credential.helper= push --dry-run origin repair/integrated
```
Output:
```
To https://github.com/Rob1Ham/ln-lean.git
 * [new branch]      repair/integrated -> repair/integrated
```
RC = **0**.

No push occurred in either attempt (dry run). `git ls-remote origin` after the dry run confirms no new remote ref.

## 5. Recommended push command for the parent

```bash

GIT_ASKPASS=/tmp/ln-askpass.sh GIT_TERMINAL_PROMPT=0 git -c credential.helper= push origin repair/integrated
```

- The `-c credential.helper=` is **required** in this environment; without it the gh/store helpers send a
  stale credential and GitHub returns 403 (reproduced above).
- Add `--dry-run` first if the parent wants a second confirmation; otherwise this exact command is the
  verified-safe form.
- Do **not** add `--force`, `--force-with-lease`, `--mirror`, or `--all`.
- After a successful push, `origin/repair/integrated` should equal `d5b8e9422c257f80c70c9100c2a092b676c89c23`.
