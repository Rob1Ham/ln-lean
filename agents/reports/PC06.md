## Proof outline

The proof avoids `Fintype`/mathlib by constructing an explicit finite
enumeration of all 32-byte words:

1. `sha256PropsAllByteVectors n` enumerates every list of `Fin 256` values of
   length `n` by structural recursion on `n`.
2. `mem_sha256PropsAllByteVectors` proves the enumeration is complete.
3. `sha256PropsToListFin` views a `ByteArray` as a list of `Fin 256` values;
   `sha256PropsToListFin_inj` proves this view is injective.
4. `sha256PropsZeros n` is the all-zero byte array of length `n`; distinct
   lengths give distinct inputs (`sha256PropsZeros_inj`).
5. `sha256PropsNotInjectiveFinSucc` is finite pigeonhole via
   `List.Pairwise.map`, `List.nodup_finRange`, and
   `List.Nodup.length_le_of_subset`.

Given `H` with all outputs 32 bytes and `PreimageResistant H`, restrict `H` to
`N + 1` distinct all-zero inputs, where `N` is the length of the 32-byte
enumeration.  Injectivity makes the `N + 1` outputs distinct, and every output
belongs to the enumeration of length `N`; `List.Nodup.length_le_of_subset`
gives `N + 1 ≤ N`, which `omega` closes.  Hence no such `H` is injective on
all `ByteArray`, so the `PreimageResistant` field is incompatible with
`sha256_size`.
