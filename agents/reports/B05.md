### The one obligation

```
LN-CR-007  `ByteArray` has more elements than the 2^256 possible 32-byte
           outputs, so no `H` with `(H b).size = 32` for all `b` is injective;
           hence `PreimageResistant M.sha256` is incompatible with
           `M.sha256_size`, and the consistent hypothesis is injectivity on
           32-byte preimages (`CollisionResistant`).
```

This is a real finding about the wave-A interface, not a proof shortcut:
`PrimitiveModel` requires both `sha256_size : (sha256 b).size = 32` and
`sha256_preimageResistant : ∀ x y, sha256 x = sha256 y → x = y`
(injectivity on *all* `ByteArray`). Those fields cannot both hold, so the
structure is uninhabited and every theorem quantifying over an arbitrary
`M : PrimitiveModel` is vacuous until the interface is repaired. The module
does not derive `False` from this and does not hide it.

## 4. What remains open, and the next smallest step

1. **LN-CR-007 (counting proof).** Prove that no `H : ByteArray → ByteArray`
   with 32-byte images is injective. *Next smallest step:* construct the
   family `zeros n` (all-zero `ByteArray` of length `n`) for
   `n = 0 … 2^256`; show it has `2^256 + 1` distinct elements and that its
   image under an injective `H` would be that many distinct 32-byte arrays,
   while only `256^32 = 2^256` exist. A cheaper equivalent is to prove the
   pigeonhole principle for `List (Fin 256)`/fixed-length vectors with
   `Finset.card` and transport along `ByteArray.toList`. No mathlib is
   available, so this is genuine work.
2. **Repair the interface (A2-owned).** The recommended integration fix is to
   replace `PreimageResistant sha256` in `PrimitiveModel` with the
   domain-restricted form (`CollisionResistant sha256`, i.e. injectivity on
   32-byte preimages) or to add `sha256_preimageResistantOn32`. After that,
   `paymentHash_commitment_of_preimageResistant` becomes the already-proved
   `LnLean.Crypto.Hash.paymentHash_commits`, `preimageResistant_vacuous` is
   retired, and LN-CR-007 can be closed by deletion rather than by counting.
   This is an integrator/A2 decision; B05 must not edit `Crypto/Model.lean`.
3. **HASH160 (assumption C2) is not a field.** `PrimitiveModel` has
   `hash160_size` but no RIPEMD160 operation and no
   `hash160_collisionResistant`. This module states the conditional
   composition theorem `hash160_collisionResistant_of_components`. *Next
   smallest step:* add `ripemd160 : ByteArray → ByteArray` and
   `hash160_collisionResistant : CollisionResistant hash160` (or the
   decomposition plus a RIPEMD160 CR field) to the primitive model, then
   replace the conditional theorem by a field projection.
4. **Tagged-hash digest-level separation is a reduction, not a hardness
   theorem.** `taggedHash_collision_witness` proves that a digest collision
   under distinct tags yields an explicit SHA-256 collision; the structural
   encoding lemma is unconditional. A stronger statement would need a
   computational game (outside the TCB) or a primitive assumption tailored to
   tagged inputs. *Next smallest step:* state the same reduction for the
   BOLT 12 `LnLeaf`/`LnBranch` tags when that domain is modelled, reusing
   `tagPrefix_separates_hashed_tags`.
5. **Concrete digests/test vectors are intentionally absent.** The model has
   no compression function, so BOLT 1 Appendix test vectors, length-extension
   behaviour, and constant-time execution cannot be stated here; they belong
   to an extracted implementation's test suite, not to this proof module.
