## Missing model field / next step

`ChannelAnnellation.capacitySat : Nat` has no positivity invariant, and
`GossipProps.bindChannel` copies the field unchanged; the admission path
never checks `0 < a.capacitySat`.  The minimal repair is to make the check
part of the model's bind (as `bindChannelPositive` demonstrates) or to type
the field as `{n : Nat // 0 < n}`.  This requires a model edit and is out of
scope for the read-only wave-F lane.  The L1 UTXO check that the funding
outpoint exists, is unspent, and equals the announced value remains
unmodelled; `positiveCapacity` is only its arithmetic shadow.
