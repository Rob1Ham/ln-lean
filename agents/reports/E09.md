## Remaining gap / next step

The predicate-level claim is complete. However, the model's `decodeTLV` only
parses records and has no non-increasing-type check, even though the wave-A
`TLV` docstring says it rejects them. The checked counterexample encodes two
`type = 1` records (`01 01 2a 01 01 2b`); `decodeTLV` returns them, yielding a
stream that is not `WellFormed`. Thus `decodeTLV b = some s → s.WellFormed` is
false and must not be claimed. Next step: add a model-side ordering check
(reject unless each parsed type is strictly greater than the previous one) and
prove the decoder returns `WellFormed`; the round-trip theorem additionally
needs a BigSize-domain (`InDomain`) hypothesis on every record type and value
length.
