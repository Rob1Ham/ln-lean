## 4. Open items and next smallest step

No placeholders or open obligations in the owned file. The following are
model gaps that this proof file cannot close without changing wave-A or
adding a concrete crypto instantiation:

1. **Seed-to-derivation function is not in the interface.** `Shachain` bundles
   `seed` and `derive : Nat → PerCommitmentSecret`, but no field says that
   `derive` is computed from `seed` bytes. The file proves the definitional
   facts `revocationSecret sh i = sh.derive i` and
   `scheme.pointOf (revocationSecret sh i) = scheme.pointOf (sh.derive i)`,
   which is the strongest statement available for a fixed instance. Next
   smallest step: add a wave-A field such as
   `derive_eq_of_seed_eq : sh.seed = sh'.seed → sh.derive = sh'.derive`
   (or expose `generateFromSeed : CommitmentSeed → Nat → PerCommitmentSecret`
   and set `derive := generateFromSeed seed`), then restate
   `secret_determined_by_seed`.
2. **Concrete SHA-256 shachain.** The bit-flip loop, SHA-256 compression, and
   the 49-slot placement/reconstruction algorithm are opaque. Next step:
   instantiate `Shachain` from a concrete `generate_from_seed` and prove
   `derive_size`/`derive_injective` from a collision-resistance hypothesis.
3. **Point injectivity.** `pointOf` injectivity is a secp256k1 group-law fact,
   not a field of `RevocationScheme`. Next step: add a concrete scheme (or an
   `InjectiveRevocationScheme` extension) with `pointOf_injective`, then apply
   `revocationPubkeyOfSecret_injective` unconditionally for that instance.
4. **49-slot reconstruction.** The store model records only slot `0` in
   `provideSecret` and tracks the frontier with `minSeen`; it does not prove
   that 49 slots reconstruct every secret below `minSeen`. Next step: add the
   placement function `place_secret` and the prefix-derivation lemma
   (`03-transactions.md:870` onwards, `chan_utils.rs:428`, `:465`).
5. **Byte-level "point is 32 bytes".** The mission phrase is corrected to the
   33-byte compressed point; the 32-byte claim is proved for the secret and
   the seed only.
