## Counterexample (retained, `sorry`-free)

`dust_trim_preserves_conservation_counterexample` proves

```lean
¬ (∀ (dust : Nat) (c : Commitment),
    c.totalOutputValue + c.feeSat = c.fundingValueSat →
      trimmedValue dust c + c.feeSat + anchorValue c = c.fundingValueSat)
```

via `counterexampleCommitment` (two 500-sat outputs, `feeSat = 0`, funding
1000 sat) at `DUST_LIMIT_P2WPKH = 546`. Both outputs are trimmed and the fee is
never credited, so the post-trim equation fails.

## Strongest true replacement

`conservation_of_dustFeeAccounted`:

```lean
theorem conservation_of_dustFeeAccounted {dust baseFee : Nat} {c : Commitment}
    (hgross : c.totalOutputValue + baseFee = c.fundingValueSat)
    (hacc : dustFeeAccounted dust baseFee c) :
    trimmedValue dust c + c.feeSat + anchorValue c = c.fundingValueSat
```

It is fully proved. The hypothesis-free accounting form
`conservation_with_requiredFee` (using `requiredFee = baseFee + droppedValue`)
is also fully proved.
