  - `PunishmentEffective` — `BreachPunished` plus: no transaction spending

  - `waveE_e35_punished_of_response` — a `BreachResponse` implies

- Added hypotheses: every positive theorem takes a `BreachResponse` as an
  explicit argument (secret, penalty tx, both-output spend, sweep, timely
  height, L1 confirmation). The watchtower theorem additionally takes
  `hreport : wt.reports c c.breachHeight`; liveness is *derived* from the
  report, not assumed. The counterexample takes `silentWatchtower` (live,
  empty `reports`) and `silentBridge` (`confirms := fun _ => False`).
- Statement fidelity: the catalog target
  `LnLean.Proofs.Liveness.watchtower_bridge` is statement-only and lives in
  a module this lane may not edit, so the target is realized as
  `LnLean.Proofs.WaveE.E35.waveE_e35_watchtower_bridge`. The claim is not an
  unconditional theorem of the current model. `Watchtower` has only
  `live`, `reports`, and the one-way law `reports → live`; it has no field
  `live → reports` and no field saying a reporting tower holds the
  revocation secret or broadcasts/confirms a penalty. Hence the response is
  data supplied by the caller, and the bridge theorem is conditional. The
  positive direction is faithful: it composes the four core penalty
  conditions, `bridge.confirms`, and the L1 no-double-spend effect. No claim
  was weakened silently; both the report hypothesis and the response data
  are visible in the signatures.

## Remaining gap / next step

The exact missing model field is a watchtower *action* law, e.g.

`Watchtower.responds : live → ∀ c, breachDetected c → ∃ p w confirm window, penaltyValid scheme c p w confirm window ∧ bridge.confirms p.toTx`

(or a `reports → ∃ response` bridge). Without it, `wt.live` cannot produce
`BreachResponse`. A second, already documented gap is that
`RevocationScheme.consistent` is total, so `punishable` does not bind the
witness to the commitment's secret; `HoldsRevocationSecret` plus shachain
injectivity (`waveE_e35_secret_binds_commitment`) is the strongest available
substitute. Next step: add the tower action field to the watchtower
interface (a model change, outside this lane) and derive the response from
`live` + `reports`, removing it from the theorem's hypotheses.
