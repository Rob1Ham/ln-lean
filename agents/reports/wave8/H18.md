## Exact result

### Model boundary

The local record is the 18 mandatory fields in BOLT 2 wire order.  Its exact
mandatory payload is **319 bytes**:

```
chain_hash 32 + temporary_channel_id 32 + 6*u64 48 + feerate_per_kw 4
+ 2*u16 4 + 6*point 198 + channel_flags 1 = 319
```

This matches `H17.basePayloadLength = 319` / `H17.msgLength_none`.  The
wave-7 sketch's `313` is a different projection: it omits `chain_hash` (32)
and `channel_reserve_satoshis` (8) and adds an assumed 34-byte
`shutdown_scriptpubkey` TLV (`319 - 32 - 8 + 34 = 313`).  H18 models the exact
mandatory payload with an **empty TLV stream**.

```
structure OpenChannelMsg where
  chainHash : List UInt8
  temporaryChannelId : List UInt8
  fundingSatoshis : Nat
  pushMsat : Nat
  dustLimitSatoshis : Nat
  maxHtlcValueInFlightMsat : Nat
  channelReserveSatoshis : Nat
  htlcMinimumMsat : Nat
  feeratePerKw : Nat
  toSelfDelay : Nat
  maxAcceptedHtlcs : Nat
  fundingPubkey : List UInt8
  revocationBasepoint : List UInt8
  paymentBasepoint : List UInt8
  delayedPaymentBasepoint : List UInt8
  htlcBasepoint : List UInt8
  firstPerCommitmentPoint : List UInt8
  channelFlags : UInt8
```

```
def TYPE_OPEN_CHANNEL : Nat := 32
def PAYLOAD_LEN : Nat := 319

def decodePayload (l : List UInt8) : Option OpenChannelMsg
def decodeFrame : List UInt8 → Option OpenChannelMsg
```

`decodeFrame` is the payload-only BOLT 1 abstract frame
`type(2) || payload-length(2) || payload`; the length counts the payload only.
It is not a BOLT 8 transport decoder.

### Generic rejection theorems

```lean
theorem decodePayload_eq_none_of_length_ne {l : List UInt8}
    (h : l.length ≠ PAYLOAD_LEN) : decodePayload l = none

theorem decodePayload_some_length {l : List UInt8} {m : OpenChannelMsg}
    (h : decodePayload l = some m) : l.length = PAYLOAD_LEN

theorem decodeFrame_eq_none_of_length_lt_four {l : List UInt8}
    (h : l.length < 4) : decodeFrame l = none

theorem decodeFrame_eq_none_of_type_ne {a b c d : UInt8} {rest : List UInt8}
    (h : be16 a b ≠ TYPE_OPEN_CHANNEL) :
    decodeFrame (a :: b :: c :: d :: rest) = none

theorem decodeFrame_eq_none_of_declared_ne {a b c d : UInt8}
    {rest : List UInt8} (h : be16 c d ≠ rest.length) :
    decodeFrame (a :: b :: c :: d :: rest) = none

theorem decodeFrame_eq_none_of_payload_length_ne {a b c d : UInt8}
    {rest : List UInt8} (ht : be16 a b = TYPE_OPEN_CHANNEL)
    (hd : be16 c d = rest.length) (hl : rest.length ≠ PAYLOAD_LEN) :
    decodeFrame (a :: b :: c :: d :: rest) = none
```

Thus the decoder rejects **every** wrong-length payload (all truncations and
oversizes), every header with type ≠ 32, every declared-length/actual-length
mismatch, and every header shorter than four bytes.

## Scope caveats

- **Local model, not the shared `Messages.lean` record.**  H18 does not import
  or edit H13/H14/H17; it is reproducible even if those lanes are reshaped.
  Its field list and 319-byte length match H17's mandatory-payload model.
- **Optional TLVs are rejected.**  A legitimate
  `open_channel_tlvs`/`upfront_shutdown_script` payload is rejected by the
  exact-length rule.  This is a parser boundary, not a BOLT 2 interoperability
  claim; `H17.msgLength_some` models the extended length.  Extending the parser
  would require an explicit TLV reader and new truncation tests.
- **Payload-only framing.**  BOLT 8 transport framing counts the type in the
  two-byte length.  `decodeFrame` deliberately rejects such a frame; transport
  bytes must be unframed first (`LnLean.Wire.Transport.unframeTransport`).
- **No semantic validation.**  `channel_reserve >= dust_limit`, funding amount
  ranges, chain-hash identity, `feerate_per_kw`, and `to_self_delay` semantics
  are not checked.  No signature is carried and no cryptographic check occurs.
- **Point validation is only the compressed tag.**  `0x02`/`0x03` is checked;
  curve membership, subgroup, and infinity are outside the model.
- **Undefined `channel_flags` bits are accepted**, matching the BOLT 2 receiver
  requirement to ignore them; `decodePayload_sample_flags_ff` pins this.
- No transport attribution, peer identity, or handshake-phase claim is made.
