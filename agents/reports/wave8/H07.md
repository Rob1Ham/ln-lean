## Scope caveats
- **No well-formedness hypothesis is needed** for the definition, the field
  projections, or the byte equality: they hold for every `HtlcWire` and every
  `ByteArray` scriptCode. `HtlcWire.WellFormed` is used only for the outpoint
  length and the `preimageBytes` length corollary.
- **`scriptCode` is an explicit parameter and is not synthesized.** For a real
  P2WSH HTLC spend it is the BOLT 3 offered/received HTLC witness script; that
  synthesis is lane H08. The vector uses an opaque 34-byte placeholder and
  claims no script semantics.
- **`amountSat` is the value of the spent HTLC output** (an output of the
  commitment transaction), not `HtlcWire.valueSat`. `valueSat` is the value of
  the produced second-stage output, so identifying them would be unsound; the
  module leaves the spent amount explicit.
- The hash type `ht` is arbitrary in the theorem. BOLT 3 signs with
  `SIGHASH_ALL` (`0x01`); the vector uses `SIGHASH_NONE|ANYONECANPAY` (`0x82`)
  only so the three sub-hashes are the BIP 143 zero vector and the layout is
  decidable.
- Only **preimage byte equality** is proved. No digest injectivity, signature
  binding, or C3 claim; that remains the separate H12/PR-06 conditional path.
- The outpoint txid is kept in consensus-internal order; display-order
  conversion is lane H10 and is deliberately not assumed here.
- The HTLC transaction spends exactly one commitment output, so input index
  `0` is exact. Multi-input second-stage layouts are outside BOLT 3.
