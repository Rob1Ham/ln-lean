### Non-force integration sequence

1. Fill the decision register; land license/notice/vendor-metadata commits.
2. Freeze the candidate `R`; confirm clean tree and recompute `origin/main`,
   its distance, and the tag list at `R`.
3. Gate `R` with the 20-row evidence matrix: clean tree, toolchain, catalog
   (strict + planned), `check.sh`, `check-final.py`, conformance, anchors,
   vendor, full build, axiom audit, exact `sorry` scan, `git diff --check`,
   clean-clone source gates, clean-clone build or explicit skip, CI, license,
   tag, artifact, release-note review.
4. Push `repair/integrated` **non-force**; verify the remote head equals `R`.
5. Open a PR to `main` with the H48 skeleton and required source-gates check;
   disclose whether the build job actually ran.
6. Merge fast-forward or with a merge commit; never force-push `main` and never
   squash/rebase the reviewed release commit without re-gating the result.
7. Tag the exact gated commit (or recorded merge commit) with the chosen signing
   method; verify `git rev-parse <TAG>^{commit}`; push only that tag, non-force.
8. Publish the approved release assets; record tag object hash, commit, tree,
   toolchain, CI URL, artifact hashes, and rollback owner.
