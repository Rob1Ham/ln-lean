## Exact result

### 1. Full `PrimitiveModel` counterexample (not a bare function)

```lean
def c1CollisionModel : PrimitiveModel            -- sha256 := c1OnlyHash

theorem c1CollisionModel_collisionResistant :
    CollisionResistant c1CollisionModel.sha256

theorem c1CollisionModel_sha256 :
    c1CollisionModel.sha256 = c1OnlyHash

theorem c1CollisionModel_sha256_size (b : ByteArray) :
    (c1CollisionModel.sha256 b).size = 32

theorem c1_model_collides_on_71_byte_funding_scripts :
    ∃ (M : PrimitiveModel) (x y : ByteArray),
      CollisionResistant M.sha256 ∧
      x.size = 71 ∧ y.size = 71 ∧ x ≠ y ∧ M.sha256 x = M.sha256 y

theorem no_primitive_model_binds_71_byte_scripts :
    ¬ ∀ (M : PrimitiveModel) (x y : ByteArray),
        x.size = 71 → y.size = 71 → M.sha256 x = M.sha256 y → x = y
```

The two colliding 71-byte strings are the actual BOLT 3 templates
`TwoOfTwoScriptBytes (pub 0) (pub 0)` and
`TwoOfTwoScriptBytes (pub 1) (pub 1)`, which differ at byte 2 (the first byte
of the first pushed funding key).

### 2. Funding-output collision with well-formed parameters

```lean
theorem c1_model_does_not_bind_funding_witnessScripts :
    ∃ (M : PrimitiveModel) (p q : FundingParams),
      p.WellFormed ∧ q.WellFormed ∧
      p.witnessScript.bytes.size = 71 ∧
      q.witnessScript.bytes.size = 71 ∧
      p.witnessScript.bytes ≠ q.witnessScript.bytes ∧
      FundingScriptHashLinked M.sha256 p ∧
      FundingScriptHashLinked M.sha256 q ∧
      p.fundingScriptPubKey = q.fundingScriptPubKey

theorem c1_model_sha256_collides_on_funding_scripts :
    ∃ x y : ByteArray,
      x.size = 71 ∧ y.size = 71 ∧ x ≠ y ∧
      c1CollisionModel.sha256 x = c1CollisionModel.sha256 y
```

This is the concrete failure of "the P2WSH funding output binds the revealed
71-byte script" **inside a model where C1 holds**: two distinct, well-formed,
hash-linked funding records have the same on-chain `scriptPubKey`.

### 3. Domain-separated script commitment and its conditional closure

```lean
def scriptDomainTag : ByteArray                    -- fixed 32-byte tag
def scriptCommitment (H : ByteArray → ByteArray) (scriptBytes : ByteArray) :
    ByteArray := H (scriptDomainTag ++ scriptBytes)

theorem scriptDomainTag_size : scriptDomainTag.size = 32

theorem scriptCommitment_preimage_size (s : ByteArray) :
    (scriptDomainTag ++ s).size = 32 + s.size

theorem scriptCommitment_preimage_ne_payment_preimage
    (s : ByteArray) (pre : Preimage) (hs : s.size = 71) (hpre : pre.Valid) :
    scriptDomainTag ++ s ≠ pre.bytes

theorem scriptCommitment_hash_linked (H : ByteArray → ByteArray)
    (n : FundingNegotiation) :
    FundingScriptHashLinked (scriptCommitment H)
      (n.toFundingParams (scriptCommitment H))

theorem scriptCommitment_binds_witnessScript
    (H : ByteArray → ByteArray) (p : FundingParams) (revealed : ByteArray)
    (hlink : FundingScriptHashLinked (scriptCommitment H) p)
    (hrev : p.fundingScriptPubKey = p2wsh (scriptCommitment H revealed))
    (hpair : CollisionFreeOn H (scriptDomainTag ++ revealed)
      (scriptDomainTag ++ p.witnessScript.bytes)) :
    revealed = p.witnessScript.bytes

theorem scriptCommitment_binds_twoOfTwo
    (H : ByteArray → ByteArray) (n : FundingNegotiation)
    (hwf : (n.toFundingParams (scriptCommitment H)).WellFormed)
    (revealed : ByteArray)
    (hrev : (n.toFundingParams (scriptCommitment H)).fundingScriptPubKey =
      p2wsh (scriptCommitment H revealed))
    (hpair : CollisionFreeOn H (scriptDomainTag ++ revealed)
      (scriptDomainTag ++
        (n.toFundingParams (scriptCommitment H)).witnessScript.bytes)) :
    IsTwoOfTwoScript
        (n.toFundingParams (scriptCommitment H)).localFundingKey
        (n.toFundingParams (scriptCommitment H)).remoteFundingKey revealed ∧
      revealed.size = 71

theorem c1_does_not_imply_script_commitment_injectivity :
    ¬ ∀ (M : PrimitiveModel) (x y : ByteArray),
        x.size = 71 → y.size = 71 →
        M.sha256 (scriptDomainTag ++ x) = M.sha256 (scriptDomainTag ++ y) →
        x = y

theorem scriptCommitment_pair_admission_satisfiable :
    ∃ H : ByteArray → ByteArray,
      (∀ b : ByteArray, (H b).size = 32) ∧
      CollisionFreeOn H
        (scriptDomainTag ++ TwoOfTwoScriptBytes (pub 0) (pub 0))
        (scriptDomainTag ++ TwoOfTwoScriptBytes (pub 1) (pub 1))

theorem payment_binding_and_script_binding_are_independent :
    CollisionResistant c1CollisionModel.sha256 ∧
      (∃ x y : ByteArray, ... M.sha256 x = M.sha256 y) ∧
      (∃ H, ... CollisionFreeOn H ...)
```

## Scope caveats

- `c1CollisionModel` is an **admissible `PrimitiveModel`**, not FIPS 180-4
  SHA-256.  Its purpose is exactly the faithfulness claim: the C1 *interface
  field* (collision resistance on 32-byte inputs plus 32-byte width) does not
  imply 71-byte injectivity.  This is not a claim that real SHA-256 has a
  collision.
- The domain-separated closure is **conditional** on the finite pair admission
  at the tagged preimages.  That is unavoidable: `CollisionResistantOn H 71`
  is impossible for any 32-byte-output hash by pigeonhole, and the model
  contains no computational collision-finding assumption.  The theorem shows
  the separated commitment composes with the existing construction
  definitionally; it does not manufacture script binding from C1.
- Domain separation here separates *preimage spaces* (103-byte tagged script
  inputs versus 32-byte payment preimages).  It does not claim output-space
  separation without a cryptographic assumption; the module proves the
  negative result `c1_does_not_imply_script_commitment_injectivity`.
- All existing finite admissions are preserved and unchanged:
  `FundingScriptTargets.CollisionFreeOn`,
  `FundingScriptTargets.fundingScriptHash_binds_witnessScript`,
  `FundingScriptTargets.fundingScriptPubKey_binds_witnessScript`,
  `FundingScriptTargets.fundingScriptPair_assumptions_satisfiable`,
  and `FundingLinkTargets.constructed_binds_twoOfTwo`.  The module imports
  them and only instantiates `H := scriptCommitment H`.
- The concrete keys are repeated 33-byte filler keys (`0x00…`/`0x01…`); they
  are valid compressed-key *widths*, not claimed to be on-curve secp256k1
  points.  The model's `PubKey.Valid` is the 33-byte width predicate.
- No full `lake build`, no catalog/traceability/root/gate script was run.
