-- Headline: the HTLC-wire preimage digest is the vendored BIP 143 digest.
theorem htlcBip143Preimage_digest_eq_signatureHashBip143Impl (h : HtlcWire)
    (scriptCode : ByteArray) (ht : UInt32) (amountSat : UInt64) :
    LnLean.Bitcoin.Sighash.digest
        (htlcBip143Preimage h scriptCode ht amountSat).toPreimage =
      Bitcoin.SigHash.signatureHashBip143Impl h.toTx 0 (bL scriptCode) ht
        (amountSat.toNat : Int)

-- Interface-level value consumed by the checker wiring.
theorem htlcBip143Preimage_digest_eq_interface (h : HtlcWire)
    (scriptCode : ByteArray) (ht : UInt32) (amountSat : UInt64) :
    LnLean.Bitcoin.Sighash.digest
        (htlcBip143Preimage h scriptCode ht amountSat).toPreimage =
      Bitcoin.SigHash.signatureHashBip143 h.toTx 0 ⟨scriptCode⟩ ht
        (amountSat.toNat : Int)

-- Digest = SHA256d of exactly the preimage bytes (no re-encoding).
theorem htlcBip143Preimage_digest_eq_dshaL (h : HtlcWire)
    (scriptCode : ByteArray) (ht : UInt32) (amountSat : UInt64) :
    LnLean.Bitcoin.Sighash.digest
        (htlcBip143Preimage h scriptCode ht amountSat).toPreimage =
      Bitcoin.SigHash.dshaL
        (bL (htlcBip143Preimage h scriptCode ht amountSat).preimageBytes)

-- In-range index 0 equals the model witness-v0 sighash.
theorem htlcBip143Preimage_digest_eq_sighashWitnessV0 (h : HtlcWire)
    (scriptCode : ByteArray) (ht : UInt32) (amountSat : UInt64) :
    LnLean.Bitcoin.Sighash.digest
        (htlcBip143Preimage h scriptCode ht amountSat).toPreimage =
      LnLean.Bitcoin.Sighash.sighashWitnessV0 h.toTx 0 scriptCode ht
        (amountSat.toNat : Int)

-- BOLT 3 uses SIGHASH_ALL (0x01).
theorem htlcBip143Preimage_digest_eq_vendor_sighashAll (h : HtlcWire)
    (scriptCode : ByteArray) (amountSat : UInt64) :
    LnLean.Bitcoin.Sighash.digest
        (htlcBip143Preimage h scriptCode 0x01 amountSat).toPreimage =
      Bitcoin.SigHash.signatureHashBip143Impl h.toTx 0 (bL scriptCode) 0x01

## Scope caveats

- **H07 dependency.** `htlcBip143Preimage` is imported from
  `LnLean.Proofs.WaveH.H07` and is definitionally
  `Bip143Preimage.ofTx h.toTx 0 scriptCode ht amountSat`. H09 uses no H07
  theorem except `HtlcWire.toTx_vin_length`,
  `htlcBip143Preimage_toPreimage`, and
  `htlcBip143Preimage_preimageBytes_size`. If the parent drops H07, apply the
  fallback below.
- `scriptCode` is explicit. The 22-byte/179-byte vector pins the *serialization*
  size and layout; it is **not** a claim that this byte string is a BOLT 3 HTLC
  witness script. Script synthesis is H08. The general size theorem
  `htlcBip143Preimage_preimageBytes_size` (H07) covers any scriptCode under
  `HtlcWire.WellFormed`; `htlc_witnessScriptSizeOk_iff` records BIP 143's
  10,000-byte witness-script premise.
- `amountSat` is the value of the **spent HTLC output** (a commitment output),
  not `HtlcWire.valueSat` (the produced second-stage output). They are separate
  parameters on purpose; identifying them would be unsound. `amountSat` is a
  `UInt64`, so `serAmountL (amountSat.toNat : Int)` is non-negative and
  round-trips (`htlc_amount_nonneg`, `htlc_serAmountL_amount`); the vendor's
  `amount ≥ 0` assert is discharged by construction, not assumed.
- `ht` is explicit for all theorems; the `0x01` instance is provided for BOLT 3
  and the omission-free sub-hash forms are recorded in
  `htlc_sighashAll_subhashes`. No hidden `SIGHASH_ALL` assumption is used for
  the general theorem.
- The hash is the vendored seam SHA-256 (`Bitcoin.SigHash.dshaL`). C1
  (collision resistance) is **not** used; no digest injectivity, signature
  binding, or transaction validity is claimed. The out-of-range behaviour is
  Core's `assert(nIn < vin.size())` totalized to the zero digest in both the
  vendored implementation and the model.
- The digest equality is for the vendored *preimage/digest* only. It does not
  prove that `h.toTx` is confirmable, that `amountSat` is the outpoint's actual
  value, or that the signature is valid (C3/context are outside this lane).
