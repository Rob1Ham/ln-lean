## Exact result

### The actual downstream site

`siteTx` lifts the signer-side state that `ProducedFrom` constrains to the
rich consumer transaction, changing only the dust limit and scripts;
`siteMessage` is exactly the honest `commitmentSignedFullOfState` projection:

```lean
def siteTx (st : SignedState) (dustLimitSat : Nat)
    (toLocalScript toRemoteScript localAnchorScript remoteAnchorScript :
      ScriptPubKey)
    (htlcScript : CommitmentHTLCOutput → ScriptPubKey) : CommitmentTx

def siteMessage (st : SignedState) (commitSig : EcdsaSig)
    (sigAt : SignedHtlc → EcdsaSig) : CommitmentSigned

theorem siteTx_commitment ... :
    (siteTx st dustLimitSat ... htlcScript).commitment = st.toCommitment

theorem siteMessage_htlcSignatures (st : SignedState) (commitSig : EcdsaSig)
    (sigAt : SignedHtlc → EcdsaSig) :
    (siteMessage st commitSig sigAt).htlcSignatures = st.htlcs.map sigAt

theorem siteMessage_covers_legacy (st : SignedState) (commitSig : EcdsaSig)
```

### The construction-site counterexample

`trimmedSiteState` has one offered 500-sat HTLC, 500-sat funding, zero fee, and
a 1000-sat dust limit at the site:

```lean
theorem trimmedSiteTx_consumerOutputs :
    (siteTxSimple trimmedSiteState 1000).consumerOutputs =
      [CommitmentOutput.htlc .local 500]

theorem trimmedSiteTx_migratedConsumerOutputs :
    (siteTxSimple trimmedSiteState 1000).migratedConsumerOutputs = []

theorem legacyCoverage_not_preserved_at_construction_site :
    ProtocolCoverageTargets.CoversHtlcOutputs trimmedSiteMessage
        (siteTxSimple trimmedSiteState 1000).commitment ∧
      ¬ CommitmentConsumer.CoversMigratedOutputs trimmedSiteMessage
        (siteTxSimple trimmedSiteState 1000)

theorem exists_construction_site_coverage_loss :
    ∃ (st : SignedState) (m : CommitmentSigned) (tx : CommitmentTx),
      tx.commitment = st.toCommitment ∧
        0 < tx.dustLimitSat ∧
        tx.UsesRecordNet ∧
        ProtocolCoverageTargets.CoversHtlcOutputs m st.toCommitment ∧
        ¬ CommitmentConsumer.CoversMigratedOutputs m tx
```

The existential form carries `tx.UsesRecordNet`, so the loss is genuine BOLT 3
net trimming at the record field, not a projection mismatch.

### Sufficient premise

```lean
def MigratesConsumerIdentity (tx : CommitmentTx) : Prop :=
  tx.migratedConsumerOutputs = tx.consumerOutputs

def SiteNormalForm (tx : CommitmentTx) : Prop :=
  tx.UsesRecordNet ∧ 0 < tx.dustLimitSat ∧ tx.Migrated

def SiteNoTrim (tx : CommitmentTx) : Prop :=
  tx.UsesRecordNet ∧
    0 < tx.dustLimitSat ∧
    tx.dustLimitSat ≤ tx.commitment.toLocalSat ∧
    tx.dustLimitSat ≤ tx.commitment.toRemoteSat ∧
    (∀ h ∈ tx.commitment.htlcs, tx.dustLimitSat ≤ h.netAmountSat)

theorem siteCoverage_iff_of_consumerIdentity (m : CommitmentSigned)
    (tx : CommitmentTx) (h : MigratesConsumerIdentity tx) :
    CommitmentConsumer.CoversMigratedOutputs m tx ↔
      ProtocolCoverageTargets.CoversHtlcOutputs m tx.commitment

theorem siteCoverage_iff_of_normalForm (m : CommitmentSigned) (tx : CommitmentTx)
    (h : SiteNormalForm tx) :
    CommitmentConsumer.CoversMigratedOutputs m tx ↔
      ProtocolCoverageTargets.CoversHtlcOutputs m tx.commitment

theorem siteCoverage_iff_of_noTrim (m : CommitmentSigned) (tx : CommitmentTx)
    (h : SiteNoTrim tx) :
    CommitmentConsumer.CoversMigratedOutputs m tx ↔
      ProtocolCoverageTargets.CoversHtlcOutputs m tx.commitment
```

`SiteNoTrim` implies `SiteNormalForm`
(`siteNormalForm_of_noTrim`), and both imply
`MigratesConsumerIdentity` (`consumerIdentity_of_normalForm`,
`consumerIdentity_of_noTrim`). The concrete witness is outside both premises
(`trimmedSiteTx_not_migrated`, `trimmedSiteTx_not_normalForm`,
`trimmedSiteTx_not_noTrim`).

### `Migrated` alone is insufficient

A record can satisfy `Migrated` against an explicit transaction net projection
while `Commitment.migrateNet` still filters on the 500-sat record field:

```lean
theorem mismatchedNetSiteTx_migrated : mismatchedNetSiteTx.Migrated
theorem mismatchedNetSiteTx_not_usesRecordNet :
    ¬ mismatchedNetSiteTx.UsesRecordNet

theorem migrated_alone_does_not_preserve_coverage :
    ∃ (st : SignedState) (m : CommitmentSigned) (tx : CommitmentTx),
      tx.commitment = st.toCommitment ∧
        tx.Migrated ∧
        0 < tx.dustLimitSat ∧
        ¬ tx.UsesRecordNet ∧
        ProtocolCoverageTargets.CoversHtlcOutputs m st.toCommitment ∧
        ¬ CommitmentConsumer.CoversMigratedOutputs m tx
```

This pins `UsesRecordNet` as a necessary conjunct of the normal form.

```lean
        (CommitmentTx.ofCommitment
          (commitmentPairOfBalances localParams remoteParams b fee number
            funder).localCommitment
```

`commitmentPairOfBalances` has no HTLCs by construction, so it cannot witness
HTLC-coverage loss; the failure genuinely needs the `SignedState` site. The
surviving 2000-sat witness shows `SiteNoTrim` is satisfiable.

## Scope caveats

- **Coverage is positional, not cryptographic.**  `CoversHtlcOutputs` is the
  BOLT 2 count predicate `htlcSignatures.length = htlcOutputCount …`. No
  signature is verified, no sighash is constructed, and witness/consensus
  validity is out of scope.
- **The site lift is exact but minimal.**  `siteTx` changes only
  `dustLimitSat` and the script fields on `CommitmentTx.ofCommitment`; the
  commitment record is definitionally `st.toCommitment`. Script bytes do not
  participate in any coverage predicate, so the concrete witness uses empty
  scripts.
- **`UsesRecordNet` is not removable.**  `migrated_alone_does_not_preserve_coverage`
  shows `Migrated + 0 < dust` is insufficient when the transaction's net
  projection differs from `CommitmentHTLCOutput.netAmountSat`. The normal form
  must state `Migrated` against the record field.
- **The normal form is sufficient, not the weakest condition.**  The exact
  boundary is `MigratesConsumerIdentity`; `SiteNormalForm` / `SiteNoTrim` are
  checkable BOLT 3 survivor conditions that imply it. A trivial no-HTLC site
  satisfies preservation without `Migrated`, which is why
  `commitmentPairOfBalances_coverage_preserved` is stated separately.
- **The no-trim premise is pointwise on emitted record values.**  It bounds
  `toLocalSat`, `toRemoteSat`, and each `h.netAmountSat`; second-stage HTLC
  fees and child transactions are not modelled.
- **Retained theorems are restatements.**  The D12, wave-4, and wave-7
  counterexamples are aliased to their existing proofs, not re-proved or
  strengthened. The wave-7 provenance theorem only identifies the arithmetic;
  it does not assert a new wire-format result.
- **Only the lane module was built.**  No full-tree build or root-import
  integration is claimed.
