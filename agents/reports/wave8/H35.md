## Scope caveats

- **Local vectors only.**  `tests/conformance/vectors.json`,
  `scripts/check-conformance.py`, `LnLean/Proofs/ConformanceTargets.lean` and
  `LnLean/Proofs/WaveH/H35.lean`'s shared fixture wiring are untouched.  The
  module is a candidate source of new vectors; the parent decides whether to
  transcribe any of them into the shared JSON.
- **Finite-vector conformance plus class-level minimality, not a full
  implementation test.**  No IO error behaviour, `MAX_BUF_SIZE` allocation
  limits, real byte-cursor/`Read` semantics, streaming concatenation, or
  namespace/known-type policy is covered.  rust-lightning byte-for-byte
  behaviour is not claimed.
- **Minimality is stated at the class level.**  `encode` width exactness comes
  from `encode_size_*`; the decoder rejection covers every *wider* form of the
  same value.  "No shorter form exists" is the class-size iff lemma
  (`(encode n).size = 1 ↔ n < 0xfd`, etc. from `TLVProps`), not a separate
  quantification over all shorter byte strings.
- **Domain boundary is explicit.**  `decode_encode` in `BigSize.lean` requires
  `n < 2^64`; above it `encode` truncates and the resulting `0xff` payload is
  non-minimal.  The collision theorem is the concrete witness that an
  unconditional round trip is false.
- The streaming decoder still ignores trailing bytes (existing model behaviour,
  not changed here); this module does not add a trailing-byte vector.
