## Scope caveats

- **Artifact-only:** resolves neither `OPS-01` (no vendor artifact published,
  no URL/checksum chosen) nor `OPS-03` (no tag, PR, merge, push, or branch
  change). `main` is untouched.
- **Not build evidence:** steps 10–11 are printed but never executed. Green
  source gates do not prove the tree builds.
- **Vendor state is inferred, not provisioned:** step 8 is never invoked; a
  present-but-modified snapshot is only caught by the separately printed
  `verify-vendor.sh` command.
- **Anchors are deferred without `refs/rust-lightning`:** the script never
  fetches; a clean checkout needs the pinned fetch before step 7 can pass.
- **Baseline counts:** the `expect:` lines (204 Lean files, 202 imports,
  48/79 catalog, 306 anchors) are wave-7 facts at `50d78ed`; the parent must
  refresh them after integration. The script does not enforce them.
- **Shared worktree is not a clean checkout:** other lanes' untracked modules
  change counts and may contain in-progress `sorry`; use `--root` with a
  `git archive` export.
- **Tracked-input check is skipped in non-Git exports:** there is no `.git` in
  an export, so tracking is only re-verified against the real worktree.
- **No JSON output:** the printed digests are the machine-checkable record.
