### Model

```lean
abbrev StoreEpoch := Nat

structure UpdateSlot where
  scid : ShortChannelId
  direction : Bool
deriving Repr, BEq, DecidableEq

structure EpochStore where
  store : CanonicalStore
  epoch : StoreEpoch
  annStamps : List (ShortChannelId × StoreEpoch)
  updStamps : List (UpdateSlot × StoreEpoch)

def EpochStore.annStamp (e : EpochStore) (scid : ShortChannelId) : Option StoreEpoch
def EpochStore.updStamp (e : EpochStore) (s : UpdateSlot) : Option StoreEpoch

def StampBounded (e : EpochStore) : Prop :=
  (∀ p ∈ e.annStamps, p.2 ≤ e.epoch) ∧ (∀ p ∈ e.updStamps, p.2 ≤ e.epoch)

noncomputable def epochStep (verify : SigVerifier) (e : EpochStore) :
    GossipMessage → EpochStore
```

`epochStep` mirrors `applyGossipCanonicalStore` branch for branch: an admitted
announcement prepends `(a.shortChannelId, e.epoch + 1)` to `annStamps`, an
admitted update prepends `((u.shortChannelId, u.direction), e.epoch + 1)` to
`updStamps`, an admitted node announcement stamps no channel slot, and a
rejected message returns `e` unchanged.  A log is newest-first and `annStamp` /
`updStamp` read the head-most entry for the key.

slot for `sc1` holds `u0` at stamp `2`; applying the superseding `u1` keeps the

honest boundary of the epoch semantics: re-announcing the identical head record
is admitted, bumps the epoch, and leaves the gossip content unchanged.

## Scope caveats

- **The epoch is model-side bookkeeping, not a wire field.**  `StoreEpoch` is
  `Nat`; BOLT 7 has no store epoch.  The real replacement clock remains the
  per-direction `timestamp` (plus local wall-clock policy outside the spec).
  `epochStep_update_requires_newer_timestamp` is the only bridge to that rule;
  no theorem claims the epoch is a hash, a consensus value, or an on-chain fact.
- **Epoch = number of admissions, not a content hash.**  An admitted message can
  leave the store content unchanged; `epoch_admission_gossip_noop_witness`
  exhibits exactly that for a re-announced identical channel record and records
  that the epoch still advances.  No theorem asserts the converse.
- **The stamp logs are histories.**  They grow with admitted channel messages;
  no compaction, persistence, crash recovery, or authenticated-log property is
  modelled or claimed.
- **No new admission power.**  `epochStep_store` proves the store projection is
  exactly `applyGossipCanonicalStore`; the epoch layer neither accepts nor
  rejects anything the canonical gates would not.  `epochStep_store_change_requires_admitted`
  is the converse direction for content-changing steps only.
- **Reachable-store invariants are inherited, not re-proved from scratch.**
  `reachableEpochStore_store_reachable` projects reachability, and
  `reachableEpochStore_invariant` derives `CanonicalStoreAdmitted` from the
  wave-7 theorem.  `StampBounded` is the genuinely new reachable invariant.
- **Signature verification remains abstract** (`SigVerifier`, assumptions
  C3/C4/C8); no unforgeability, network, liveness, chain-hash, UTXO, or
  rate-limit claim is made.
- **The raw store is untouched.**  `raw_applyGossip` remains append-only and is
  still not a function refinement of canonical admission; the three negative
  results above are re-exported with their wave-7 statements unchanged.  No
  theorem identifies raw and canonical transitions.
- Concrete witnesses use the local `acceptAll` verifier and local byte keys;
  they are existence proofs, not claims about a production verifier.
