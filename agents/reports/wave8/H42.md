### Epoch boundary model
```lean
structure EpochStore where
  gossip : GossipState
  nodeKeyOf : NodeId → PubKey
  epoch : Nat

def EpochStore.toCanonicalStore (es : EpochStore) : CanonicalStore

def rawBoundaryStore (s : GossipState) (msgs : List GossipMessage) : GossipState
def rawBoundaryExtension (es : EpochStore) (msgs : List GossipMessage) : EpochStore
noncomputable def canonicalBoundaryStore (verify : SigVerifier)
    (cs : CanonicalStore) (msgs : List GossipMessage) : CanonicalStore
noncomputable def canonicalBoundaryExtension (verify : SigVerifier)
    (es : EpochStore) (msgs : List GossipMessage) : EpochStore
```
Both boundary extensions advance `epoch` by one. The raw operator folds raw `applyGossip` (append-only announcements/updates under the global update clock); the canonical operator folds `applyGossipCanonicalStore` (signature/registration/attribution/supersession gates, replacement semantics).

### Exact single-boundary condition (why raw append cannot preserve canonicality)
```lean
theorem canonicalAnnouncements_cons_iff (a : ChannelAnnellation)
    (l : List ChannelAnnellation) :
    CanonicalAnnouncements (a :: l) ↔
      CanonicalAnnouncements l ∧
        ∀ b ∈ l, b.shortChannelId = a.shortChannelId → b = a

theorem canonicalAnnouncements_applyGossip_announcement_iff
    (s : GossipState) (a : ChannelAnnellation) :
    CanonicalAnnouncements (applyGossip s (.channelAnnouncement a)).announcements ↔
      CanonicalAnnouncements s.announcements ∧
        ∀ b ∈ s.announcements, b.shortChannelId = a.shortChannelId → b = a

theorem canonicalAnnouncements_applyGossip_announcement_of_fresh
    (s : GossipState) (a : ChannelAnnellation)
    (hcanon : CanonicalAnnouncements s.announcements)
    (hfresh : ∀ b ∈ s.announcements, b.shortChannelId ≠ a.shortChannelId) :
    CanonicalAnnouncements (applyGossip s (.channelAnnouncement a)).announcements

theorem raw_announcement_boundary_cannot_preserve_conflict
    (s : GossipState) (a b : ChannelAnnellation)
    (hb : b ∈ s.announcements)
    (hscid : b.shortChannelId = a.shortChannelId)
    (hne : b ≠ a) :
    ¬ CanonicalAnnouncements (applyGossip s (.channelAnnouncement a)).announcements
```
The exact `iff` is the boundary obstruction: raw append preserves `CanonicalAnnouncements` only if every stored record with the incoming `short_channel_id` is **literally** the incoming record. Any genuinely new same-channel record (different key, capacity, digest, or signatures) breaks canonicality. Canonical admission gates the record and **replaces** by channel; raw append has no replacement/rejection step. Hence the two transitions cannot have the same announcement projection on conflicting input, at any epoch.

### Sharp conditional (batch) refinement
```lean
def BoundaryAdmissible (verify : SigVerifier) :
    GossipState → CanonicalStore → List GossipMessage → Prop
-- []      => True
-- m :: ms => CanonicalMessageAdmitted verify cs m ∧ RawClockAdmits s m ∧
--            FreshMessage s m ∧
--            BoundaryAdmissible verify (applyGossip s m)
--              (applyGossipCanonicalStore verify cs m) ms

theorem rawBoundaryStore_eq_canonical_of_admissible
    {verify : SigVerifier} {s : GossipState} {cs : CanonicalStore}
    {msgs : List GossipMessage} (hstate : s = cs.gossip)
    (hadm : BoundaryAdmissible verify s cs msgs) :
    rawBoundaryStore s msgs = (canonicalBoundaryStore verify cs msgs).gossip

theorem rawBoundaryExtension_eq_canonical_of_admissible
    {verify : SigVerifier} {es : EpochStore} {msgs : List GossipMessage}
    (hadm : BoundaryAdmissible verify es.gossip es.toCanonicalStore msgs) :
    (rawBoundaryExtension es msgs).gossip =
      (canonicalBoundaryExtension verify es msgs).gossip

theorem canonicalBoundaryStore_reachable (verify : SigVerifier)
    (cs : CanonicalStore) (msgs : List GossipMessage)
    (h : ReachableCanonicalStore verify cs) :
    ReachableCanonicalStore verify (canonicalBoundaryStore verify cs msgs)

theorem canonicalBoundaryExtension_reachable {verify : SigVerifier}
    {es : EpochStore} (msgs : List GossipMessage)
    (h : ReachableCanonicalStore verify es.toCanonicalStore) :
    ReachableCanonicalStore verify
      (canonicalBoundaryExtension verify es msgs).toCanonicalStore
```
The batch theorem is the sharpest true refinement on the common domain: canonical gate + raw global clock + freshness at every step. It is sufficient, not necessary in general (an identical duplicate record can also preserve canonicality; see the exact single-step `iff`). Freshness plus the gate is exactly what raw insertion lacks.

### Exact boundary witness (negative)
```lean
theorem epoch_boundary_witness :
    ∃ (verify : SigVerifier) (es : EpochStore) (a : ChannelAnnellation),
      ReachableCanonicalStore verify es.toCanonicalStore ∧
        es.epoch = 1 ∧
          (canonicalBoundaryExtension verify es
            [GossipMessage.channelAnnouncement a]).gossip = es.gossip ∧
            (rawBoundaryExtension es
              [GossipMessage.channelAnnouncement a]).gossip ≠ es.gossip ∧
              ¬ CanonicalAnnouncements
                (rawBoundaryExtension es
                  [GossipMessage.channelAnnouncement a]).gossip.announcements

theorem epoch_boundary_raw_announcement_breaks_canonicality
    (es : EpochStore) (a b : ChannelAnnellation)
    (hb : b ∈ es.gossip.announcements)
    (hscid : b.shortChannelId = a.shortChannelId)
    (hne : b ≠ a) :
    ¬ CanonicalAnnouncements
      (rawBoundaryExtension es
        [GossipMessage.channelAnnouncement a]).gossip.announcements
```
The concrete witness is the `acceptAll` verifier, a canonically reachable epoch-1 store holding `ann1` (`sc1`, `nodeKey1 = kA`), and the conflicting re-announcement `annConflict` (`sc1`, `nodeKey1 = kC`, `kC ≠ kA`). At the next boundary:
- canonical admission rejects `annConflict` (`CompatibleWithStore` fails), so the gossip store is unchanged;
- raw extension appends `annConflict` and stores `[annConflict, ann1]`, so `CanonicalAnnouncements` fails.

### Impossibility
```lean
theorem no_canonical_preserving_raw_boundary_extension :
    ¬ ∃ F : EpochStore → List GossipMessage → EpochStore,
        (∀ (es : EpochStore) (msgs : List GossipMessage),
          (F es msgs).gossip.announcements =
            (rawBoundaryExtension es msgs).gossip.announcements) ∧
        (∀ (es : EpochStore),
          CanonicalAnnouncements es.gossip.announcements →
            ∀ msgs : List GossipMessage,
              CanonicalAnnouncements (F es msgs).gossip.announcements)

theorem no_epoch_advancing_canonical_preserving_raw_boundary_extension :
    ¬ ∃ F : EpochStore → List GossipMessage → EpochStore,
        (raw announcement projection equality) ∧
        (∀ es msgs, (F es msgs).epoch = es.epoch + 1) ∧
        (canonicality preservation)
```
The operator may inspect the epoch counter and the entire batch, and may do anything to updates, node announcements, and the registration map. It still cannot both implement raw announcement appending and preserve `CanonicalAnnouncements`; the batch `[ann1, annConflict]` from the empty epoch-0 store is the counterexample. Advancing the epoch explicitly does not help.

### Non-vacuity
```lean
theorem epoch_boundary_refinement_witness :
    ∃ (verify : SigVerifier) (es : EpochStore) (msgs : List GossipMessage),
      msgs ≠ [] ∧
        (rawBoundaryExtension es msgs).gossip =
          (canonicalBoundaryExtension verify es msgs).gossip ∧
        (rawBoundaryExtension es msgs).epoch = es.epoch + 1
```
At epoch 0, admitting the fresh `ann1` through both paths is a non-vacuous instance of the conditional refinement.

## Scope caveats
- `EpochStore.epoch` is a model-level counter, not a BOLT 7 wire field, consensus timestamp, or dissemination round. The boundary operator can inspect it; the impossibility holds even with that extra power.
- `BoundaryAdmissible` is a sufficient common-domain predicate. For a single raw announcement append the exact condition is the `iff` above; for a batch, freshness is sufficient but not necessary (an exact duplicate record preserves canonicality).
- The batch refinement is stated on the **gossip projection** only: canonical admission may rebind `nodeKeyOf`, while raw extension leaves it unchanged. No registration refinement is claimed.
- `SigVerifier` remains abstract; `CompatibleWithStore` is a registration policy, not a proof of key ownership. No unforgeability (C3/C4/C8), network, liveness, chain-hash, UTXO, or rate-limit claim is added.
- Raw update insertion remains governed by the single global `latestUpdateTimestamp`; the canonical per-slot gate is strictly different (`canonical_admission_strictly_weaker_than_raw_clock` is preserved unchanged).
