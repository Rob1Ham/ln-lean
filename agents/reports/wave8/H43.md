## 2. Result in one paragraph

The module defines an explicit adversary: `Packet` is a message with a send
time, and `AdvSchedule` records, per packet, the delivery time (`Option Nat`,
`none` = permanent drop), the retransmission attempt times, and which attempts
the adversary lets through. The finite-delay, fair-lossy, and unbounded-retry
premises are ordinary `Prop`s: `Causal`, `FiniteDelay gst delta`,
`AttemptTimesMonotone`, `AttemptTimesUnbounded`, and `FairAttempts`. Under
those premises `eventual_delivery_of_fair_attempts` produces an actual delivery
at or after `gst` with the explicit bound `attemptTime p k ≤ d ≤
attemptTime p k + delta`. The complementary inclusion instance models an
adversarial round server: `RoundFair serve n` lets the adversary order the `n`
pending slots arbitrarily inside every round, and
`eventual_inclusion_of_roundFair` proves every slot is served inside any
window of length `2 * n`. Both premises are shown necessary:
`dropAll_not_eventually_delivered`, `dropAll_not_fair`, and
`starvation_counterexample` exhibit adversaries for which the conclusion
fails. Two provably different fair adversaries (`roundRobin`, `reverseServe`)
give distinct first-service times for slot `0` (`0` versus `n - 1`), so the
model admits genuine adversarial choice. The module then bridges to the tree:
a finite-delay adversary yields `LnLean.Security.PartiallySynchronous`
(`toSecurity_partiallySynchronous`, so `INV-10` is non-vacuously inhabited),
and an explicit `lockinAt k` channel-event schedule is proved `NoLoss` and
`Fair`, so `LnLean.Proofs.Liveness.fair_awaitingLockin_eventually_normal`
fires on the concrete `witnessChannel` (lock-in exactly at tick `3` for
`k = 2`). Admission is tied to the inclusion model by
`addHtlc?_some_mem`: a pending slot can only be an HTLC accepted by
`LnLean.Proofs.Payment.addHtlc?`.

## 3. Exact signatures

### 3.1 Adversarial delivery model

```lean
structure Packet where
  tag : Nat
  sendTime : Nat

structure AdvSchedule where
  deliverAt : Packet → Option Nat
  attemptTime : Packet → Nat → Nat
  attemptScheduled : Packet → Nat → Bool

def Causal (s : AdvSchedule) : Prop :=
  ∀ p d, s.deliverAt p = some d → p.sendTime ≤ d

def DeliveredBy (s : AdvSchedule) (p : Packet) (t : Nat) : Prop :=
  ∃ d, s.deliverAt p = some d ∧ d ≤ t

def EventuallyDelivered (s : AdvSchedule) (p : Packet) : Prop :=
  ∃ d, s.deliverAt p = some d

def FiniteDelay (s : AdvSchedule) (gst delta : Nat) : Prop :=
  ∀ p, gst ≤ p.sendTime →
    ∃ d, s.deliverAt p = some d ∧ p.sendTime ≤ d ∧ d ≤ p.sendTime + delta

def FairAttempts (s : AdvSchedule) (p : Packet) : Prop :=
  ∀ K, ∃ k, K ≤ k ∧ s.attemptScheduled p k = true

def AttemptTimesUnbounded (s : AdvSchedule) (p : Packet) : Prop :=
  ∀ B, ∃ k, B ≤ s.attemptTime p k

def AttemptTimesMonotone (s : AdvSchedule) (p : Packet) : Prop :=
  ∀ k, s.attemptTime p k ≤ s.attemptTime p (k + 1)
```

### 3.4 The eventual-inclusion instance

```lean
def IncludedBy (serve : Nat → Nat) (i T : Nat) : Prop :=
  ∃ t, t ≤ T ∧ serve t = i

def RoundFair (serve : Nat → Nat) (n : Nat) : Prop :=
  ∀ r i, i < n → ∃ k, k < n ∧ serve (r * n + k) = i

theorem roundFair_served_in_round {serve : Nat → Nat} {n : Nat}
    (h : RoundFair serve n) {i : Nat} (hi : i < n) (r : Nat) :
    ∃ t, r * n ≤ t ∧ t < r * n + n ∧ serve t = i

theorem roundFair_eventually_included {serve : Nat → Nat} {n : Nat}
    (h : RoundFair serve n) {i : Nat} (hi : i < n) :
    ∃ t, serve t = i

theorem roundFair_first_round {serve : Nat → Nat} {n : Nat}
    (h : RoundFair serve n) {i : Nat} (hi : i < n) :
    IncludedBy serve i (n - 1)

theorem roundFair_served_within_window {serve : Nat → Nat} {n : Nat}
    (hn : 0 < n) (h : RoundFair serve n) {i : Nat} (hi : i < n)
    (t₀ : Nat) :
    ∃ s, t₀ ≤ s ∧ s < t₀ + 2 * n ∧ serve s = i

theorem eventual_inclusion_of_roundFair {serve : Nat → Nat} {n : Nat}
    (hn : 0 < n) (h : RoundFair serve n) {i : Nat} (hi : i < n)
    (t₀ : Nat) :
    ∃ T, t₀ ≤ T ∧ T ≤ t₀ + 2 * n ∧ IncludedBy serve i T

theorem includedBy_mono {serve : Nat → Nat} {i T T' : Nat}
    (h : IncludedBy serve i T) (hle : T ≤ T') : IncludedBy serve i T'
```

def lockinAt (k : Nat) : Liveness.Scheduler :=
  fun n =>
    if n < k then ProtocolEvent.fundingSigned
    else if n = k then ProtocolEvent.fundingLocked
    else ProtocolEvent.commitmentSigned

theorem lockinAt_run (c : Channel) (k : Nat)
    (hphase : c.phase = ChannelPhase.awaitingLockin) :
    ∀ n, ∃ cn, Liveness.runPrefix c (lockinAt k) n = some cn ∧
      cn.phase = (if n ≤ k then ChannelPhase.awaitingLockin

theorem lockinAt_noLoss (c : Channel) (k : Nat)
    (hphase : c.phase = ChannelPhase.awaitingLockin) :
    Liveness.NoLoss c (lockinAt k)

## 5. Scope caveats

1. **Conditional by construction.** Every temporal conclusion carries
   `FiniteDelay`, `FairAttempts`, `AttemptTimesUnbounded`, or `RoundFair` as an
   explicit hypothesis. There is no theorem of the form "every message is
   eventually delivered" without them; `dropAll_not_eventually_delivered` and
   `starvation_counterexample` are the mechanized refutations of the
   unconditional readings.
2. **No full network model.** `deliverAt` is arbitrary data over abstract
   packets identified by a `Nat` tag. There is no wire encoding, no onion, no
   peer/channel joint state, and no message-to-`ProtocolEvent` map. The
   `lockinAt` bridge supplies the channel-event schedule directly, as in
   `LnLean.Proofs.Liveness`.
3. **`RoundFair` is an assumption about the scheduler, not a block-production
   theorem.** It models "every pending slot is served once per round" for a
   fixed `n`; it says nothing about fees, block space, or eviction. The `2 * n`
   window is a scheduling bound, not a confirmation bound. The served slot is
   assumed not to be evicted between admission and service.
4. **`PartiallySynchronous` is a predicate, not a claim about a real network.**
   `toSecurity_partiallySynchronous` and `invPartialSynchrony_nonvacuous` show
   the predicate is satisfiable by a non-trivial schedule; they do not prove
   that any deployed network satisfies it.
5. **`SEC-01` is untouched.** No game, advantage, reduction, corruption model,
   or negligibility claim is made. Only the adversary/schedule side is made
   concrete. `CR-01`/`SEC-01` remain out of scope for an agent lane.
6. **No probabilistic reasoning.** `FairAttempts` is "every suffix contains a
   scheduled attempt", a deterministic patience condition, not a probability-1
   statement. `FiniteDelay` is a hard bound, not an expectation.
7. **`n` is a parameter.** If `n = 0`, `RoundFair` is vacuous and
   `eventual_inclusion_of_roundFair` correctly requires `0 < n`. The `2 * n`
   bound degenerates for `n = 0`, which is why the premise is explicit.
8. **Witness channel is syntactically concrete, not cryptographically valid.**
   Keys are `ByteArray.empty` placeholders; the witness is a non-vacuity
   witness for the lifecycle relation, not a valid channel.
