Checks, in order:

1. Artifact exists (`3` if missing), is a directory, and has `lakefile.lean`
   plus `Bitcoin.lean` (`1` otherwise). A symlinked artifact root is a note by
   default and a failure with `--strict-root`.
2. Manifest: exactly 119 newline-terminated entries; `SHA256  ./path` grammar;
   64 lowercase hex; relative `./` paths only; no `//`, backslash, `..`,
   `./.lake`, or `./.git`; no duplicates; `LC_ALL=C` path order.
3. Digest: from inside the artifact,
   `find . \( -path ./.lake -o -path ./.git \) -prune -o -type f -print0`
   → `LC_ALL=C sort -z` → `xargs -0 -r sha256sum`, compared path-by-path with
   separate missing/extra/changed counts and up to five example paths each.
   Pruning matches `scripts/verify-vendor.sh`.
4. Symlinks: `find` over the resolved tree (same prune), `-type l`. Absolute
   targets print `absolute symlink` (OPS-04); relative targets print
   `relative symlink`; every symlink fails, matching `fetch-vendor.sh`'s
   rejection of all non-regular archive members.

Digest and symlink findings are both reported before the single failure exit.
The script writes only to a `mktemp -d` scratch directory (removed on exit),
uses no network and no Git, and prints repository-relative paths plus a stable
manifest SHA-256.

## Scope caveats

- **OPS-04 is detected, not fixed.** The nested absolute symlink remains in the
  read-only vendor tree. Removing it and repacking the snapshot is a vendor
  action outside this lane.
- **OPS-01 is not closed.** A verified directory still needs a published,
  checksummed archive or a committed snapshot, plus the redistribution/license
  decision in `docs/LICENSE-DECISION.md`. This verifier only makes the
  candidate check reproducible.
- **Directory input, not archive input.** Safe archive extraction remains
  `fetch-vendor.sh --from-tarball ... --dry-run`; this script checks the
  extracted tree. It does not validate tar member types.
- **Manifest covers bytes, not modes.** File permissions/ownership/mtime are
  outside the pin, matching the existing gate. The strict two-field
  `sha256sum` grammar does not support whitespace in paths (none exist in the
  119 files).
- **`.lake`/`.git` are pruned** exactly like `verify-vendor.sh`; they are
  ignored rather than required absent. `.lake`/`.git` symlinks are therefore
  invisible to this check, as they are to the digest gate.
- **No CI or existing vendor script was edited**, per lane ownership. The patch
  below is a recommendation.
