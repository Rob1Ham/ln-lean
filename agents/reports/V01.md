## 4. Wiring

No change was needed; the existing dependency already resolves the public
package:

```lean
require «core» from "vendor/btc-lean-core"
```

* Public `spec/core/lakefile.lean` declares `package «core»` and a default
  `lean_lib Bitcoin`, matching the requirement.
* It also declares two `default_target` executables (`btclean`, `capstone`);
  as a path dependency only the imported library closure is built, so neither
  is part of this build.
* The clone is still **not** a path dependency (`check-public-reference.sh`
  enforces this): the build reads `vendor/`, which happens to be a byte-exact
  copy. Builds therefore work offline without `/home/ubuntu/btc-lean-public`.
* `.lake` was created inside the vendor dir (`4` oleans) and is excluded from
  the manifest by `verify-vendor.sh`.
