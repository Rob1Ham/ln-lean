### New helper lemmas (same file, before the two targets)

1. `find?_map_ite_of_find?` — list induction: if `l.find? p = some c` and
   `p (f c) = true`, then the positionwise updated list
   `l.map (fun x => if p x then f x else x)` finds `f c`.
2. `advanceReceived_channelId` — `advanceReceived` preserves `channelId`;
   it only rewrites `reestablish`.
3. `findChannel_updateChannel_of_id` — if `findChannel s cid = some c` and the
   update preserves the channel identifier (`(f c).channelId = c.channelId`),
   then `findChannel (updateChannel s cid f) cid = some (f c)`.

The identifier-preservation hypothesis in (3) is necessary: an arbitrary
update may rename the channel, after which `findChannel` no longer returns it.
Both uses take `f = advanceReceived`, covered by (2).  The two target
statements are therefore proved as stated, without weakening.
