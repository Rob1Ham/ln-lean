## 4. What remains open / next smallest proof step

1. **`LN-FEAT-012` (the only `sorry`).**
   `accepts_intersection_of_accepts`: intersecting two accepted vectors is
   accepted. Next step: rewrite `(intersection f g).requires n` with
   `intersection_requires`; if it is `true`, `Bool.and_eq_true` gives
   `f.requires n = true`, contradicting `accepts_iff_no_unknown_required`
   applied to `hf` when `known n = false`.
2. **Concrete BOLT 1 wire codec.**  `FeatureCodec` is only an interface.
   Next step: implement the big-endian byte parser/packer for
   `InitMsg.features` (LDK `from_be_bytes` at
   `lightning-types/src/features.rs:1031-1035`) and prove `byteLen_eq` and
   `decode_bounded`; then `decoded_bit_lt_wire` applies directly.
3. **Concrete BOLT 9 dependency table.**  `DependenciesSatisfied` is generic.
   Next step: instantiate the table from `refs/bolts/09-features.md:35-60`
   (e.g. `basic_mpp → payment_secret`, `option_scid_alias →
   option_zeroconf`) and prove the individual entries.
4. **Byte-level script templates.**  This module selects an abstract
   `ScriptTemplate`; it deliberately does not import `LnLean.Bitcoin.Seam`
   (wave-A import restriction). Next step: in a Bitcoin proof module, connect
   `.anchoredToRemote` to the BOLT 3 keyed-anchor P2WSH script and
   `.staticRemoteKeyToRemote` to P2WPKH.
5. **Anchors channel-type dependency.**  `ChannelTypeAnchorsImplyStatic` is a
   predicate, not a theorem about a bare `init` vector: a peer can offer the
   even anchor bit in `init` without the static-remotekey bit.  Next step:
   model the `channel_type` TLV and prove the implication there.
6. **Global/local split.**  BOLT 1 combines both bitmaps with OR before the
   receive rule; `union` is proved commutative but the protocol code does not
   yet call it (this module models one combined vector).
