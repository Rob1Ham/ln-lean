- Added hypotheses:
  - `d < 2^16` in the injectivity theorems. BOLT 2 carries `to_self_delay` as
    a `u16` (`refs/bolts/02-peer-protocol.md:697`, `:921`), so the protocol
    discharges this, not the user. The bound cannot be dropped: delays `0` and
    `65536` produce the same script (counterexample theorem).
  - `revocationKey.bytes.size = 33` for the fixed byte offsets: the prefix is
    `OP_IF` + 34-byte key push + `OP_ELSE`. Sensitivity of the *delay push
    itself* to the delay does not use this hypothesis.
  - `hinj : sha256 s₁ = sha256 s₂ → s₁ = s₂` only in
    `waveD_d42_toLocal_output_commits_delay`, i.e. the missing crypto bridge
    for the P2WSH output. No `HashesMatch` or SHA256 fact is assumed anywhere
    else.
  - `p.toSelfDelay = c.contestDelay` in `waveD_d42_contestDelay_delayBytes`
    because `LnLean.Channel.Commitment` (a value record) has no function that
    builds a script; the script builder takes `CommitmentParams.toSelfDelay`.

- Statement fidelity: the model's `toLocalWitnessScript` encodes the delay as
  the fixed-width push `pushData (pushUInt16LE d)`, i.e. exactly
  `[0x02, d % 256, (d / 256) % 256]` immediately followed by `OP_CSV OP_DROP`.
  This module proves that byte layout at fixed offsets 36..40, extracts the
  little-endian value back, and proves injectivity on the BOLT-valid range, so
  "commits to the CSV contest delay" is literal at the `Script.bytes` level.
  BOLT 3 (`refs/bolts/03-transactions.md:113-135`) and LDK
  `get_revokeable_redeemscript` (`chan_utils.rs:687-700`) use the same template.
  Caveats are explicit: the model is *not* minimal `CScriptNum` encoding (for
  `d < 128` it emits an extra length byte and trailing zero), and no script
  interpreter is modelled, so this is a byte-template commitment, not CSV
  spend-condition enforcement.

## Remaining gap / next step

- SHA256 is not modelled: `CommitmentParams.HashesMatch` is an unproved `Prop`
  and `waveD_d42_toLocal_output_commits_delay` assumes hash injectivity. Next

  the injectivity hypothesis from collision resistance over the 77-byte script
  domain.
- The scaffold's delay push is fixed-width, not minimal `CScriptNum`. Next
  step: define minimal script-number encoding, prove it agrees with this
  encoding on `[0, 2^16)`, and re-state size bounds for BOLT-3 bit-exactness.

  `commitmentPairOfBalances` sets from the counterparty's parameter). Next
  step: add a `Commitment → CommitmentParams` bridge or a script field to the
  commitment record.
