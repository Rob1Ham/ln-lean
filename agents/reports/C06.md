## 3. Proof approach

`Step` permits only these phase edges (from `step_allowedPhaseTransition`):
`negotiating→negotiating`, `negotiating→awaitingLockin`,
`awaitingLockin→awaitingLockin`, `awaitingLockin→normal`,
`normal→normal`, `normal→shuttingDown`, `shuttingDown→closed`. Hence there
are two facts behind `LN-CH-010`:

1. **Entry lemma** `step_target_normal_eq_fundingLocked`: if a step starts
   outside `normal`, ends in `normal`, and its target phase is `normal`, the
   event is `fundingLocked`. It is proved by `cases h <;> simp_all` over the
   ten `Step` constructors: every constructor other than `fundingLocked`
   either leaves the phase equal to the source phase or moves it to a
   different phase, contradicting the two phase hypotheses.
2. **Trace induction** `fundingLocked_mem_of_trace_to_normal`: induct on
   `Trace`. The `nil` case contradicts the target being `normal` while the
   source is not. In the `cons` case, split on the phase of the intermediate
   channel:
   * if it is `normal`, the entry lemma identifies the head event as
     `fundingLocked`, so it is the head of the label list;
   * if it is not `normal`, the induction hypothesis applies to the tail
     trace (same `normal` endpoint, non-`normal` tail source), and the label
     is pushed under the head with `List.mem_cons_of_mem`.

The public theorem instantiates the auxiliary lemma with
`c.phase = negotiating`, using `decide` for `negotiating ≠ normal`.

Note on the auxiliary entry lemma: the source-not-`normal` premise is
essential and is *not* a weakening of the target. Without it the entry lemma
is false — a `normal` channel taking `commitmentSigned` / `revokeAndAck` /
`updateFee` has a `normal` target but the event is not `fundingLocked`. In
the actual target theorem the source is `negotiating`, so the premise is
satisfied. The target theorem itself is unchanged and remains true for the
model.

Helpers added (both `private`, both used):
`step_target_normal_eq_fundingLocked`,
`fundingLocked_mem_of_trace_to_normal`.

## 4. False or unprovable statements

None in this file. The only previously open site, `LN-CH-010`, is now closed
for the model as written. The broader literal BOLT 2 ordering claim
("`channel_ready` only after `funding_signed`") remains false in this model,
as already documented in the module docstring and in `agents/reports/B10.md`:
`Channel` has no `fundingSignedSeen`/history field, and
`channelReady_reachable_without_fundingSigned` exhibits the counterexample
trace `[fundingCreated, fundingLocked]`. That is a separate, already-recorded
model gap and does not affect the statement proved here.

The model also still enables `shutdown` only in `normal`, whereas BOLT 2
permits it before `channel_ready`; that is likewise a pre-existing scope note
in the module docstring, not a new obligation.
