## 4. Open items and next smallest steps

1. **`LN-CONS-004` — erase-based settlement.**
   `settleHTLCOutputErase_conserved` is the only `sorry`. The needed list
   lemma is
   `htlcOutputsValue (hs.erase h) + h.amountSat = htlcOutputsValue hs`
   for `h ∈ hs`. Next step: prove it by induction on `hs`, splitting on
   `h = head`; the duplicate-valued case is handled because `List.erase`
   removes exactly one occurrence and all occurrences contribute the same
   `h.amountSat`.
2. **Anchor-aware `commitmentPairOfBalances` (wave A / A3 gap).**
   `commitmentPair_anchorCounterexample` is a *checked* counterexample: with
   anchors enabled, `commitmentPairOfBalances` emits 660 sat of anchor
   outputs but does not debit them, so
   `outputs + fee = funding + 660`. The current pair theorem is therefore
   stated with `anchorOutputs = false`. Next step: in the wave-A builder,
   subtract `if anchorOutputs then 2 * anchorOutputSat else 0` from the
   funder's output on each commitment, then restate
   `commitmentPairOfBalances_conserved` without the two anchor hypotheses.
   B30 does not edit `LnLean/Channel/Commitment.lean` (owned by A3).
3. **Import collision between wave-A HTLC modules.**
   `LnLean.Channel.Types` and `LnLean.Channel.HTLC` both declare a
   top-level `LnLean.Channel.HTLC` structure. Importing both fails with
   `environment already contains 'LnLean.Channel.HTLC.direction'`, so this
   file imports `LnLean.Channel.Commitment` (which supplies
   `CommitmentHTLCOutput`) and does **not** import `LnLean.Channel.HTLC`.
   Consequence: the BOLT 2 `addHTLC`/`fulfillHTLC`/`failHTLC` guard
   predicates and the SHA-256 preimage condition are not linked here.
   Next step for the integrator/A3/A4: rename one of the two structures
   (for example `Types.HTLC` → `ChannelHTLC`), then B13/B30 can import both
   and connect protocol transitions to the commitment ledger.
4. **Second-stage HTLC transactions.** Their 663/703 weights and the
   second-stage fee split are not modelled. The conservation file treats a
   `CommitmentHTLCOutput.amountSat` as the already-net commitment output.
   A follow-up should state
   `htlcOutputValue h fee + secondStageFee = floor(amountMsat)` with the
   fee and dust hypotheses.
5. **Policy/liveness.** Watchtower liveness, penalty-fee economics, RBF,
   anchor CPFP, and the question of whether either party actually broadcasts
   the latest commitment are out of scope, consistent with
   `docs/ASSUMPTIONS.md`.
