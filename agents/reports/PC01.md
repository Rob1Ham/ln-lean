The proof reduces the erase form to the caller-decomposition form.  The key
list fact is

```
htlcOutputsValue (l.erase h) + h.amountSat = htlcOutputsValue l    (h ∈ l)
```

which is proved by induction on `l` and holds **without** a `Nodup`
hypothesis.  `List.erase` matches the whole `CommitmentHTLCOutput` record
(direction, amount, CLTV expiry, state), so it removes exactly one occurrence;
if equal records are duplicated, every such record has the same `amountSat`,
so subtracting `h.amountSat` is still exact.  Crediting that value to the
funder/receiver balance (`fundingSide`), while the fee and funding value are
untouched, then gives the same `CommitmentConserved` equation as `c`.

Because the derived `BEq` on `CommitmentHTLCOutput` is fieldwise and is not
definitionally `instBEqOfDecidableEq`, the generic `LawfulBEq` instance does
not synthesize for it.  The small `*_eq_of_beq` / `*_beq_refl` helpers supply
exactly the two facts needed by `List.erase_cons` (reflexivity and
`a == b = true → a = b`), proved by constructor case analysis.  This avoids
adding global instances or axioms.
