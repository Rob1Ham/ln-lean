## 4. What remains open, and next smallest step

The file is `sorry`-free. The open items are model boundaries, each recorded
with an `-- OBLIGATION:` marker:

1. **LN-COMMIT-003 — state-transition bridge.** The commitment counter law is
   proved only for the isolated `CommitmentCounterStep` fragment, and the
   conditional theorem assumes a relation refines it. B09 may not import
   `LnLean.Channel.State`, so the refinement
   `State.Step c e c' → CommitmentCounterStep c c'` and the identification of
   `Commitment.commitmentNumber` with `Channel.localCommitmentNumber` /
   `remoteCommitmentNumber` are not in the tree.
   *Next step:* in B10's `StateMachineProps.lean` (or after the import ban is
   lifted), prove `step_localCommitmentNumber` / `step_remoteCommitmentNumber`
   cases and instantiate
   `commitmentNumber_changes_only_on_valid_step` with
   `R := LnLean.Channel.Step`.
2. **LN-COMMIT-005 — anchors in `commitmentPairOfBalances`.** The A3 pair
   construction subtracts only the fee from the funder; with anchors the
   output sum plus fee is `funding + 660` (the checked theorem
   `commitmentPair_conservation_anchors_gap` states the exact discrepancy).
   *Next step:* A3 changes the two `toLocal`/`toRemote` branches to subtract
   `commitmentAnchorTotal`; B09's theorem then becomes the BOLT 3
   conservation law.
3. **LN-COMMIT-004 — single-anchor exception.** BOLT 3
   `:148-160` and LDK `chan_utils.rs:1928-1943` emit only one anchor when
   there are no HTLCs and the corresponding commitment output is absent.
   `Commitment.commitmentOutputs` always emits two.
   *Next step:* extend the A3 output function with the “output exists or
   HTLCs exist” predicate; then `zeroHtlcCommitment_outputs_anchors` splits
   into the one-anchor and two-anchor cases.
4. **LN-COMMIT-006 — BIP 69+CLTV ordering.** The model fixes the group order
   (`to_local`, `to_remote`, HTLCs, anchors); BOLT 3 §6 requires a final
   sort. Determinism of the model list is proved, sortedness is not.
   *Next step:* define a BIP 69 comparator over `CommitmentOutput` and prove
   the model order agrees when scripts/values already sort in that order, or
   prove the canonical sorted list permutation-equal to the model list.
5. **Dust trimming of `to_local`/`to_remote`.** The model trims only at
   `0`, not against the broadcaster’s dust limit. `buildCommitment` and
   `addHtlc` therefore take pre-trimmed values; no theorem claims the
   trimming rule itself.
6. **HTLC dust threshold.** `Commitment.addHtlc` takes the second-stage HTLC
   fee as an explicit argument. The A3 `isDust` does not include it, so the
   caller must pass `dustLimit + htlcTxFee` to match BOLT 3/LDK.

The easiest next proof (smallest step) is item 5/6: add a `dustLimit` truncation
function in A3 and prove `commitmentOutputs (trim c d) = commitmentOutputs c`
when all values already exceed `d`, reusing
`Commitment.commitmentOutputs_eq_decomposition` and
`outputsValue_toLocalOutputs`.
