# PC36 — L1 penalty output bridge

## Scope

Target: `LnLean/Proofs/PhaseC2/PenaltyBridge.lean` (new module).
Imports `LnLean`; `set_option autoImplicit false`; namespace
`LnLean.Proofs.PhaseC2`.

The module introduces `PenaltyL1Bridge`, an explicit L1 interface with
`spends : Tx → OutPoint → Prop`, `accepted : Tx → Prop`, and an abstract
honest-ownership predicate `controls : Script → Prop`.  Both L1 obligations
are structure fields, not axioms:

* `penaltyAccepted`: every `penaltyValid` penalty transaction is accepted by L1;
* `sweepControlled`: its single sweep output is controlled by the honest party.

The no-double-spend field is stated for **distinct** transactions.  This is
the strongest true form; see "Newly discovered gap" below.

## Newly discovered gap

`LnLean.Channel.L1ScriptBridge.noDoubleSpend` quantifies over **all** `t u`,
including `t = u`.  Every transaction spends its own inputs, so the field
implies `¬ bridge.confirms tx` for every transaction that spends anything:
the source bridge accepts nothing.  The phase-C obligation is therefore
vacuously true as stated.  This module proves the gap as
`l1ScriptBridge_no_confirmed_spend` and states the corrected, inhabited
interface in `PenaltyL1Bridge.noDoubleSpend` with the required `t ≠ u`
hypothesis.  The strongest unconditional exclusive-spend statement is
`penaltyBridge_accepted_breacher_eq_penalty`: an accepted breacher spend must
be the penalty transaction itself.  For a distinct transaction,
`penaltyBridge_excludes_distinct_breacher` gives the exclusion.

## Smallest next step

Replace the source field with

```lean
noDoubleSpend : ∀ (t u : Tx) (o : OutPoint), t ≠ u →
  Spends t o → Spends u o → confirms t → ¬ confirms u
```

and rebuild `LnLean.Proofs.Channel.PenaltyProps` / `BreachProps`, whose
`penaltyValid_no_breacher_spend` statements then remain true provided the
breacher transaction is distinct from the penalty transaction.  This module
