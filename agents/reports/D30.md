## Remaining gap / next step

The conditional hypothesis is not removable in the current model. To state the
claim unconditionally one would need a collection state machine with a
per-arrival acceptance rule (reject a part when `acc + amount > total_msat`) and
an invariant that only offered parts of a consistent invoice are accepted; the
model currently has no such state or rule. The exact-equality `mppComplete`
should also be relaxed to `sumParts plan.parts ≥ plan.target.val` when
`LN-PAY-MPP-OVERPAY` is modelled.
