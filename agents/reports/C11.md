## 3. Proof approach

Target (`LN-PAY-MPP-001`): the duplicate-free collected total is invariant
under permutation of the input list.

The collector `addParts ps = ps.foldl addPart []` is not a plain dedup: it
keeps the *latest* occurrence order, so the two collected lists can differ as
lists. The proof therefore compares their sums rather than their shapes:

1. `mem_addPart`: one `addPart` step changes membership exactly by adding the
   new part (`p ∈ addPart acc q ↔ p = q ∨ p ∈ acc`).
2. `mem_foldl_addPart`: by induction on the folded list, membership in
   `ps.foldl addPart acc` is `p ∈ acc ∨ p ∈ ps`.
3. `nodup_foldl_addPart` / `nodup_addParts`: the fold of a duplicate-free
   accumulator is duplicate-free (`addPart` only conses a part that is not
   already present).
4. `mem_addParts`: `p ∈ addParts ps ↔ p ∈ ps` (collecting never drops a
   distinct part).
5. `List.perm_ext_iff_of_nodup` (Lean core) turns equal membership plus
   `Nodup` on both sides into `(addParts ps).Perm (addParts qs)`, using
   `h.mem_iff` for the input permutation.
6. `sumParts_perm` (already in the file) maps that permutation equality of
   lists to equality of the `Nat` totals.

Helper lemmas added (all used by the target proof, all `private`-free public
`theorem`s in the same file so the report/audit can see them):
`mem_addPart`, `mem_foldl_addPart`, `nodup_foldl_addPart`, `nodup_addParts`,
`mem_addParts`.

The docstring of `sumParts_addParts_perm` was updated from "left as the
