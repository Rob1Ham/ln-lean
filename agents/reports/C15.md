## 3. Proof approach

`Graph.Walk` is defined recursively on the node list; it requires
`Graph.Adjacent g a b` for each consecutive pair `a,b`.  The enumerator
`simplePathsAux` picks each next node from `g.neighbors current`, so the only
missing link is "neighbour membership implies adjacency", which is exactly
`adjacent_of_mem_neighbors` (`mem_neighbors_iff`).

The helper `simplePathsAux_walk` is proved by induction on `fuel`, generalising
over `visited`, `current`, and `p`:

* `fuel = 0`: the enumerator returns `[]`, so membership is impossible.
* `fuel + 1`, `current = dst`: the only result is `[dst]`, and `Graph.Walk [dst]`
  holds trivially.
* `fuel + 1`, `current ≠ dst`: membership in the `flatMap`/`map` gives a chosen
  neighbour `next` and a recursive result `q` with
  `p = current :: q`.  The induction hypothesis gives `g.Walk q`; the head
  lemma `Graph.simplePathsAux_head` gives `q.head? = some next`, so the second
  node of `p` is `next`; `adjacent_of_mem_neighbors hnext` supplies
  `g.Adjacent current next`, and `Graph.Walk (current :: next :: rest)` follows.

No statements were weakened and no new imports were added.  The only additions
are the `private` helper above and its proof.
