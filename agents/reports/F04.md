# F04 — Anchor debit conservation

## Target
- Marker: `LN-WF-F04`
- Module: `LnLean.Proofs.ModelHardening.F04`

## Result
- Status: conditional; the legacy counterexample is mechanized and the
  corrected theorem is proved under the BOLT 3 affordability condition.
- Build: RC 0 (one intentional `sorry`, on the retained false legacy
  statement; the corrected theorems do not depend on it).
- New definitions:
  - `anchorDebitSat` — `2 * 330` when anchors are enabled, `0` otherwise.
  - `funderDebitSat` — `fee + anchorDebitSat`.
  - `Commitment.Conserves` — output value plus fee equals funding value.
  - `Commitment.FunderDebited` — the funder can afford the debit and its own
    output equals `preFunderSat - funderDebitSat`.
  - `CommitmentPair.AnchorDebitRule` — the debit rule on both commitments of
    a pair, relative to the same off-chain balance and funder.
  - `commitmentPairWithAnchorDebit` — corrected pair constructor; identical to
    `commitmentPairOfBalances` except that the funder's own output absorbs
    `fee + anchorDebit` on each commitment.
- Main theorems:
  - `waveF_f04_legacy_anchor_gap` — legacy anchored commitments satisfy
    `outputs + fee = funding + 660` on both sides.
  - `waveF_f04_legacy_unconditional_conservation` — the faithful
    unconditional claim for the legacy constructor; false and retained with
    one `sorry` and the marker.
  - `waveF_f04_legacy_anchor_not_conserves` — both legacy anchored
    commitments fail `Commitment.Conserves`.
  - `waveF_f04_legacy_local_anchor_violates_rule` and
    `waveF_f04_legacy_anchor_violates_rule` — the legacy pair violates
    `FunderDebited` / `AnchorDebitRule`.
  - `waveF_f04_counterexample_660` — concrete 100 000-sat channel with a
    1 000-sat fee: legacy output value plus fee is 100 660.
  - `waveF_f04_counterexample_not_conserves` — the concrete legacy
    commitment fails conservation.
  - `waveF_f04_corrected_conservation` — corrected outputs plus fee equal
    funding on both commitments.
  - `waveF_f04_corrected_anchor_debit_rule` — the corrected pair satisfies
    `AnchorDebitRule`.
  - `waveF_f04_corrected_absorbs_anchor_debit` — legacy funder output equals
    corrected funder output plus the anchor debit.
  - `waveF_f04_corrected_absorbs_660` — the same statement in exact
    660-satoshi form when both commitments carry anchors.
  - `waveF_f04_counterexample_corrected_conserves` — the corrected pair
    conserves on the concrete counterexample.
- Added hypotheses:
  - Legacy gap: `fee ≤ funder balance`, preventing truncated subtraction from
    turning the exact 660-sat gap into a saturation artefact.
  - Corrected conservation/debit rule: `funderDebitSat fee anchors ≤ funder
    balance`, separately for each commitment's anchor flag. This is the
    BOLT 3 affordability precondition, not an arithmetic weakening.
- Statement fidelity:
  - The missing rule is exactly BOLT 3 §2's funder-paid anchors: both 330-sat
    anchor outputs are subtracted from the funder, in addition to the fee.
  - `anchorDebitSat true = 660` is proved by `rfl`.
  - `commitmentPairWithAnchorDebit` preserves every other field of the legacy
    constructor (holder, commitment number, funding value, HTLC list, fee,
    contest delay, anchor flag); only the funder output changes.
  - The false unconditional legacy statement is not silently replaced: it is
    retained with `sorry`, and the general gap theorem plus the concrete
    660-sat counterexample prove its negation.
  - No model or existing proof file was edited. No Wave-F module is imported.

## Missing model field / next step
`commitmentPairOfBalances` in `LnLean/Channel/Commitment.lean` still debits
only the fee. The reusable `AnchorDebitRule` and
`commitmentPairWithAnchorDebit` here supply the missing accounting, but the
canonical constructor remains A3-owned and unchanged. Integration should
adopt the anchor debit (or an explicit affordability argument) in the model,
then delete `waveF_f04_legacy_unconditional_conservation` and its `sorry`.
The other Wave-F modules remain independent and are not imported.
