## 3. Proof approach for `LN-FEAT-012`

`Acceptance` is definitionally "no unknown required bit"
(`Accepts := ¬ UnknownRequired`, with `UnknownRequired` existential over an
unknown feature whose even bit is set). The content of the obligation is that
bitwise AND cannot introduce a required bit:

* `intersection_requires` gives
  `(intersection f g).requires n = (f.requires n && g.requires n)`
  definitionally (`rfl`).
* Rewriting `hf`/`hg` through `accepts_iff_no_unknown_required` turns them into
  `∀ n, known n = false → f.requires n = false` (resp. `g`).
* For an unknown `n`, the intersection's required bit is
  `false && false = false`, so `Accepts` follows by the same equivalence.

The proof is three lines and uses only the existing lemmas
`accepts_iff_no_unknown_required` and `intersection_requires`; no helper
lemmas or definitions were added, no statement was weakened, and the
obligation marker comment was replaced by an explanatory comment since the
site is closed.
