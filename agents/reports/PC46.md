## Limits

These vectors test the model's concrete encoding/size functions, not
cryptographic behaviour. BOLT 4 ciphertext, HMAC, and key derivation remain
abstract, as documented in `LnLean.Routing.Onion`; the onion vector checks the
fixed wire-size arithmetic only. The BigSize vector set covers the canonical
boundary values requested and does not enumerate all 2^64 values.
