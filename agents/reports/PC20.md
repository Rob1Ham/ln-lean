## Proof shape

The static total is proved by `List` induction on `channels`, reusing
`CommitmentConserved` from `LnLean/Proofs/Conservation.lean` and `omega` for
the arithmetic.  The step theorem locates the changed channel with a
`before ++ c :: after` decomposition (the same device as
`settleHTLCOutputAt` in `Conservation.lean`), so no `List.get` default or
index side condition is needed.  The new and old totals are each split at the
same position, and `omega` closes the equation using the two per-channel
equations plus the funding-value hypothesis.  Append/cons decomposition is
`List.sum_append` / `List.sum_cons` plus `omega`.

No new gap found in those source theorems.  The one modelling boundary is
explicit in the new module: a multi-channel step is one-channel-local, and
`ConservedTransition` requires the funding value to be preserved (so splicing
or resizing is outside the theorem).  `ChannelLedger` in the source is a list
of historical commitments for one channel; this module deliberately uses one
current `Commitment` per channel so that `totalValue` has the intended
additive meaning.
