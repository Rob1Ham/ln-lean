## 3. Proof approach and helpers added

`LN-CR-007` is the counting argument that a map `ByteArray → ByteArray` whose
image is contained in the 32-byte strings cannot be injective. The proof is
self-contained in the file (no new imports, no Mathlib, no vendor edit):

1. **`encodeList : List UInt8 → Nat`** — base-257 positional encoding with
   every digit shifted by one: `(x.toNat + 1) + 257 * encodeList xs`. The
   shift makes every digit lie in `[1, 256]`, which removes positional
   trailing-zero ambiguity.
   * `encodeList_lt`: `encodeList l < 257 ^ l.length`.
   * `encodeList_pos`: a non-empty encoding is positive.
   * `encodeList_inj`: the encoding is injective on all byte lists. The low
     digit is recovered with `% 257` (`Nat.add_mul_mod_self_left`) and the
     tail with `/ 257` (`Nat.add_mul_div_left`), then the induction
     hypothesis applies.
2. **`unaryBytes i`** — the `i`-byte all-zero `ByteArray`; `unaryBytes_size`
   gives `.size = i`, hence `unaryBytes_inj` gives `i = j` from equality.
   These supply `257 ^ 32 + 1` distinct domain points without evaluating any
   huge literal.
3. **`encode_size` / `encode_inj`** — lift the list encoding to `ByteArray`
   via `ByteArray.ext` and `Array.toList_inj`; a 32-byte image has an
   encoding below `257 ^ 32`.
4. **`skip v x = if x < v then x else x - 1`** — used to remove the value
   `f d` from a codomain `[0, hi)`:
   `skip_lt : v < hi → x < hi → x ≠ v → skip v x < hi - 1`, and
   `skip_inj : x ≠ v → y ≠ v → skip v x = skip v y → x = y`.
5. **`natPigeonhole`** — finite pigeonhole over initial `Nat` segments:
   if `f` maps `{0, …, d-1}` into `{0, …, hi-1}` and is injective there,
   then `d ≤ hi`. Proved by induction on `d`; the step applies the
   induction hypothesis to `fun i => skip (f d) (f i)` with codomain
   `hi - 1`.
6. **Main proof** — assume `PreimageResistant H` and `∀ b, (H b).size = 32`.
   Put `f i = encodeList (H (unaryBytes i)).data.toList`. Then
   `f i < 257 ^ 32` for all `i < 257 ^ 32 + 1` (`encodeList_lt` plus
   `hsize`), while `f` is injective there (`encode_inj` on 32-byte images,
   then `PreimageResistant`, then `unaryBytes_inj`). `natPigeonhole` yields
   `257 ^ 32 + 1 ≤ 257 ^ 32`, which `omega` refutes.

The proof uses only `propext` and `Quot.sound` (checked with `#print axioms`).
No statement was weakened; `git diff b891a59` shows no `-theorem`/`-lemma`
line for this file.
