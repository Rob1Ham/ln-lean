## Why the original statement was blocked

`spendLocalBalance` subtracts with `Nat` truncation:

```lean
{ b with localBalance := ⟨b.localBalance.val - amountMsat⟩ }
```

The unconditional theorem had no hypothesis bounding `amount.val` by
`c.balance.localBalance.val`.  If the added HTLC exceeds the settled local
balance, the settled total loses only `localBalance.val`, while the new
pending HTLC contributes its full `amount.val` to `htlcInFlightValue`.  The
counterexample uses `localBalance = remoteBalance = funding = 0` and
`amount = 1` msat: the successor has `0 + 1 + 0 ≠ 0`.

Missing model bridge: a balance-changing `Step` / `update_add_htlc`
constructor that enforces `amount.val ≤ c.balance.localBalance.val`.  Once
such a constructor exists, `committed_update_preserves_ledger_of_le`
discharges the ledger equation directly.  This bridge is outside the target
file (`LnLean/Channel/State.lean`) and was not introduced.
