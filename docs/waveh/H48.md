### Rollback rules

| Situation | Non-force action |
|---|---|
| Gate fails before tagging | Fix or drop the change; do not tag. Reset only the uncommitted tree or an unpushed branch with maintainer approval. |
| Branch push rejected | Stop; merge remote changes, rerun the gate, record a new `R`; never force-push. |
| Tag created locally, not pushed | Delete only the local tag (`git tag -d "$TAG"`) with maintainer approval. |
| Tag pushed, release not published | Ask the maintainer before deleting the remote tag; record why. Avoid moving a tag others may have fetched. |
| Bad release published | Cut a new patch tag with the fix and mark the old one superseded; never move the old tag. |
| Bad merge on `main` | Revert the merge/release commits with a normal PR, rerun the gate, merge normally; never force-push `main`. |
| Vendor artifact mismatch | Withdraw the artifact, publish an advisory, rotate checksums, rebuild from the pin, and re-release under a new tag. |
